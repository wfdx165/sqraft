## 0.1.0

This release completes the gradient story. Gradients can be dragged directly on the canvas: endpoints for linear, center and radius for radial, angle for angular, half-width for diamond, plus draggable, insertable and removable color stops. A strip of gradient presets sits above the inspector editor — six built-in presets plus your own, stored locally and capped at 24. Design systems can now hold gradient tokens: `TokenEntry` gains a `gradient` type, a fill or stroke can reference one, strict mode requires token-backed stops, and agents declare them through `define_token` without any new tools. The `.sqraft` format moves from 10 to 11; 0.0.9 cannot open files saved by 0.1.0.

### Canvas gradient handles

- Select a single node with a gradient fill or stroke and drag on the canvas: endpoints for linear, center and radius for radial, angle for angular, half-width for diamond
- Drag a stop to change its position, double-click to delete it, click an empty spot on the gradient band to insert one; handle size does not scale with zoom
- One drag is one undo step; gradient handles take priority over resize handles and never block the rotate zone

### Gradient presets

- A strip of thumbnails above the gradient editor: six built-in presets — Neutral, Blue violet, Sunset, Mint, Neon, Metal
- "Save as preset" stores the current gradient on this machine (up to 24, deletable, not renameable); presets are shared across documents but do not travel with a file
- Clicking a preset replaces type, direction and stops in one undo step

### Gradient tokens

- Tokens gain a `gradient` type whose value holds type, direction, focus and stops; the design-system panel can create and edit them, and the inspector's gradient editor can create a token and switch to a reference with "Save as token"
- Fills and strokes can reference a gradient token; while referenced the editor is read-only, and changing any value detaches it into a local gradient (same behavior as color tokens)
- In strict mode every stop of a gradient token must be a color token; missing or mistyped stops render magenta and raise a diagnostic
- Agents write gradient tokens through `define_token` and reference them with `fillToken` / `strokeToken`; the tool count stays at 35

### Example document

- The Totality landing page (`file.exampleUmbra` / "Totality page example" on the welcome page) is rebuilt 1:1 from the design: background, purple haze, corona, moon shadow, foothill fade and primary button all use native gradients, and both ridgelines come straight from the design file's paths (editable anchors)
- The old approximation with low-opacity ellipses plus layer blur is gone

### Upgrade notes

- macOS builds are signed with a Developer ID certificate and notarized by Apple: they open on double-click, with no manual allow in System Settings
- The `.sqraft` format moves from `formatVersion` 10 to 11 (gradient values on tokens). **0.0.9 cannot open files saved by 0.1.0**
- Old files need no migration: the new `TokenEntry` type is additive, and documents that do not use gradient tokens are unchanged
- Known limitations: canvas handles do not edit the radial focus (still in the inspector); angular and diamond gradients are still rasterized in SVG export; presets are local to the machine and do not sync

### Manual verification

- Drag both endpoints and a stop of the linear gradient, double-click to delete one, click the band to insert one; a single `⌘Z` after releasing reverts the whole drag
- Drag each of radial / angular / diamond and confirm the handles and inspector values stay in sync
- Click all six built-in presets; save your own and restart the app to confirm it persists; check the hint at the 24-preset cap
- Inspector "Save as token" turns the node into a reference; edit the token in the design-system panel and confirm referenced nodes update
- Drag a stop while referenced → it detaches into a local gradient, and it can be linked again
- Strict mode: literal stops on a local gradient and inside a gradient token are both rejected; all-token stops work
- Delete a referenced gradient token → magenta plus a diagnostic; undo restores it
- Agent: `define_token` a gradient token → `create_node` with `fillToken` → `read_document` returns the resolved value
