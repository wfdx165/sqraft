## 0.1.0

> 草案：本文件写在实现之前，作为实现与手点验收的清单；发版前按实际落地结果改写。

*English summary:* This release completes the gradient story. Gradients can be dragged directly on the canvas: endpoints for linear, center and radius for radial, angle for angular, half-width for diamond, plus draggable, insertable and removable color stops. A strip of gradient presets sits above the inspector editor — six built-in presets plus your own, stored locally and capped at 24. Design systems can now hold gradient tokens: `TokenEntry` gains a `gradient` type, a fill or stroke can reference one, strict mode requires token-backed stops, and agents declare them through `define_token` without any new tools. The `.sqraft` format moves from 10 to 11; 0.0.9 cannot open files saved by 0.1.0.

这一版把渐变从"能在检查器里调"补成"能在画布上直接画、能存成预设、能进设计系统"。文件格式从 10 升到 11，0.0.9 打不开本版保存的文件。

### 画布渐变手柄

- 选中单个带渐变填充或描边的节点即可在画布上拖动：线性拖两端、径向拖中心与半径、角度拖角度、菱形拖半宽
- 色标可直接拖动改位置，双击删除，单击线上空白处插入；手柄尺寸不随缩放变化
- 一次拖动 = 一个撤销步；手柄优先于缩放手柄，不会挡住旋转区

### 渐变预设

- 渐变编辑器上方一排缩略图：内置中性、蓝紫、日落、薄荷、霓虹、金属 6 套
- 「＋ 存为预设」把当前渐变存到本机（上限 24 条，可删除、不可重命名），跨文档可用但不随文件分享
- 点击预设完整替换类型、方向与色标，一次撤销步

### 渐变 Token

- Token 新增 `gradient` 类型，值包含类型、方向、焦点与色标；设计系统面板可新建与编辑，检查器渐变编辑器可「存为 Token」一步创建并改为引用
- 填充与描边可以直接引用渐变 Token；引用态下编辑器只读，改任何值即断链成本地渐变（与颜色 Token 行为一致）
- 严格模式下渐变 Token 的每个色标必须是颜色 Token；缺失或类型不符时渲染洋红并给出诊断
- agent 通过 `define_token` 写渐变 Token，`fillToken` / `strokeToken` 可直接引用；工具数保持 35

### 示例文档

- 日食落地页示例（`file.exampleUmbra` / 欢迎页「日食落地页示例」）按设计稿 1:1 重建：背景、紫雾、日冕、月影、山脚渐隐与主按钮都用原生渐变，两条山脊直接取自设计稿路径（可编辑锚点）
- 不再用「低透明度椭圆 + 图层模糊」近似光晕

### 升级说明

- `.sqraft` 的 `formatVersion` 从 10 升到 11（Token 增加渐变值）。**0.0.9 无法打开 0.1.0 保存的文件**
- 旧文件无需迁移：`TokenEntry` 的新类型是加法，未使用渐变 Token 的稿子内容不变
- 已知限制：画布手柄不编辑径向焦点（仍在检查器里改）；角度与菱形渐变在 SVG 导出里仍是位图；预设不随文件走、不跨设备同步

### 手点清单

- 线性渐变拖两端与色标，双击删一个、点线上插一个，松手后 `⌘Z` 一次全部回退
- 径向 / 角度 / 菱形各拖一遍，确认手柄与检查器数值同步
- 点内置 6 套预设；存一个自己的预设并重启应用确认还在；存满 24 条时有提示
- 检查器「存为 Token」→ 节点变引用态；在设计系统面板改 Token，引用它的节点同步变化
- 引用态下直接拖色标 → 断链成本地渐变，且能重新链接
- 严格模式：本地渐变的字面色标、渐变 Token 里的字面色标都被拒；全改成颜色 Token 后正常
- 删掉被引用的渐变 Token → 洋红 + 诊断；撤销删除后恢复
- agent：`define_token` 建渐变 Token → `create_node` 用 `fillToken` 引用 → `read_document` 读到解析结果
