## 0.0.4

*English summary:* Prototype links and a present mode — click a layer to jump to another page, scroll long pages while presenting, and highlight hotspots. The same capability is exposed over MCP, so an agent can hand back a clickable design.

稿子现在能点着走了：给图层挂上链接，进演示模式点一遍。

### 新增

- 原型链接：给页面里的图层挂「点击 → 跳到某个页面」或「点击 → 返回上一屏」，随文档保存
- 检查器新增「原型」标签页：目标页面、转场（瞬间 / 淡入）、时长（60–2000ms）
- 演示模式：工具栏 ▶ 或 `⌥⌘Enter` 进入，铺满窗口单页播放；`←` 返回上一屏，`H` 高亮全部热区，`Esc`、`⌥⌘Enter` 或右上角 `×` 退出
- 页面滚动：检查器里给页面设「垂直 / 横向」，演示时可滚动，到边界停住；跳转到新页面从顶部开始，按 `←` 返回则恢复离开时的位置
- 画布连线：编辑模式选中或悬停热区，看到连到目标页的折线与页名；目标页不在视口内时退化成「→ 页面名」标签
- 拖动模式显示全量流向图：只画两端都在视口内的连线，用来一眼看出哪一页还没接上
- MCP 新增 `set_interaction` / `remove_interaction` / `list_interactions`：agent 可以直接生成可点击的稿子，`read_document` 会带上链接与滚动方向

### 改进

- 演示模式是只读的：不改选区、不改缩放、不写文档；退出后画布与你进入前完全一致
- 演示期间编辑快捷键全部让位，按 `⌫` 或 `⌘S` 不会误删节点、也不会触发保存
- 删除页面时，指向它的链接在同一步撤销里一并清理；把图层拖进主组件时链接自动清除，不留点不动的死链接
- 粘贴到别的文档时，指向原文档页面的链接自动丢弃
- 实例只继承母版的样式与结构，不复制母版上的链接（避免一个母版在每份实例里变成热区）

### 兼容性

- 文件格式从 7 升到 8：旧文件在本版本打开完全正常；**但用旧版本打开新文件会丢掉原型链接与页面滚动设置**（不会报错，是静默丢失）
- 快捷键、数据目录、已有文档的样式与排版均无变化

## 安装提示（未签名）

首次打开若提示「Sqraft 已损坏」，不是文件损坏，是 macOS Gatekeeper 拦下了未签名应用。
把 App 拖进「应用程序」后执行：

```bash
xattr -dr com.apple.quarantine /Applications/Sqraft.app
```

再打开即可。之后的版本由应用自己下载更新，不会再触发这一步。

## 已知限制

- 仅提供 macOS Apple Silicon（arm64）安装包
- 未签名、未公证，首次打开会被 Gatekeeper 拦截
- 原型链接只支持「点击」触发；悬停、长按、延时跳转尚未支持
- 检查器一次只能编辑一条交互（一条图层可以存多条，多出来的由 agent 写入、只读展示）
- 本版只做转场，不做动效：图层属性之间的平滑过渡（Smart Animate 式）、浮层与变体间过渡都还没有
- 日文 / 韩文文案由 AI 起草并抽查，可能不是母语级润色
- 日文禁则只覆盖行首标点与行尾开括号，未实现完整的 JIS X 4051
