## 0.1.1

This release adds boolean operations and multi-contour vector paths. Union, subtract, intersect and exclude are baked into one ordinary `path`, so the result stays editable with the pen and exports like any other shape; holes are real holes in both PNG and SVG, and SVG files with several subpaths no longer get rasterized on import. The `.sqraft` format moves from 11 to 12. **0.1.0 and earlier cannot open files saved by 0.1.1.**

### Boolean operations

- Union (`⇧⌥U`), subtract (`⇧⌥S`), intersect (`⇧⌥I`) and exclude (`⇧⌥E`) from the canvas or layer context menu, the `⌘K` palette, or the default shortcuts
- Operands can be paths, rectangles (including rounded corners), ellipses, polygons and lines; shapes are converted to contours in memory, no manual "convert to path" step
- Subtract always uses the bottom layer as the minuend; the other three take the top layer's name, style, parent and stacking position
- The result is a plain `path` with `fillRule: "evenodd"`, editable anchors, one undo step; operands survive only in the undo stack
- Rejected with a clear message: fewer than two layers, layers in different parents, open paths, text/images/groups/instances/components, shapes over 2000 segments after flattening, an empty intersection, and locked layers
- Round-trip is faithful: curves are flattened at 0.25px, clipped with `polygon-clipping`, and refitted to cubic Beziers with corners split at about 15°

### Multi-contour paths

- `VectorPath` is now `{ contours, fillRule }`; files at format 11 migrate automatically (one contour, `nonzero`)
- Rendering, hit testing, SVG export and the pen understand every contour; fills honour `nonzero` / `evenodd`, and a click inside a hole passes through to whatever is below
- SVG import keeps multi-subpath fills as one editable path and preserves the source `fill-rule`; open subpaths fill implicitly, matching browsers
- The pen edits anchors of any contour but cannot add or remove contours yet

### Convert to path

- `convert_to_path` turns rectangles, ellipses, polygons and lines into editable paths in place: the node id, style, parent and stacking position stay the same
- Rounded rectangles become four corner arcs, ellipses four cubic segments, polygons one anchor per vertex, lines two anchors

### Agents

- Tool count 35 → 36: added `boolean_op({ op, nodeIds })` and `convert_to_path({ nodeIds })`, removed `document.open`
- `document.open` is gone: agents can no longer pop the system file dialog or switch documents behind your back; open files from the app. Other `document.*` tools are unchanged
- `boolean_op` returns `nodeId`, `styleFrom`, `anchorCount`, and `mergedStyles: true` when the operands' fills or strokes differ (the result keeps the baseline layer's single colour)
- Anchors are read and written as `contours` + `fillRule`; `points` / `closed` remain as single-contour aliases and are rejected on multi-contour paths instead of silently dropping holes. Passing `contours` together with `closed` is rejected too
- Layers inside a component instance are rejected by both tools (`instanceInterior`): structure changes there cannot be expressed as instance overrides; edit the main component instead
- `initialize` instructions and tool descriptions explain the baked result, the `contours` contract and the instance restriction

### Upgrade notes

- The `.sqraft` format moves from `formatVersion` 11 to 12 (multi-contour vector paths). **0.1.0 and earlier cannot open files saved by 0.1.1**; 0.1.1 reads every older file and migrates on open
- Boolean results keep one colour only; there is no Figma-style non-destructive boolean group, and operands cannot be edited after the fact (undo instead)
- Deterministic limits: a single operand is rejected above 2000 flattened segments, all operands together above 10000; a path is rejected above 256 contours or 20000 anchors
- On import, a `nonzero` path whose inner contour winds the same way as the outer one is treated as a hole (even-odd nesting); the usual opposite-winding donut from SVG editors is unaffected

### Manual verification

- Select two overlapping rectangles and run each of the four operations; the result should accept anchor edits and one `⌘Z` should bring both operands back
- Subtract a circle fully inside a rectangle: the hole stays open in the canvas, in PNG export and in SVG export
- Intersect two shapes that do not overlap: the call is rejected with an explanation, and no empty node is left behind
- Subtract a shape that is completely covered by the top layer: rejected as an empty result (not as "invalid geometry")
- Try `boolean_op` on two layers inside a component instance: rejected with an instance error, and the instance stays intact
- Rotate a rectangle, then union it with another shape: the result sits in the right place
- Import an SVG icon with a hole: it stays one editable path and the hole is not rasterized
- Agent: `boolean_op` two shapes → `read_document` shows one path with `contours` / `fillRule`; `update_node` with `points` on it is rejected
