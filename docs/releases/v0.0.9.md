## 0.0.9

*English summary:* This release is the delivery wave: SVG out, SVG in, gradients, component variants and an export matrix. `Copy as ▸` and `Export as ▸` now cover SVG alongside PNG. SVG files can be dropped on the canvas and become native editable shapes, paths and text, with unsupported features rasterized element by element instead of failing the whole file. Fills and strokes accept linear, radial, angular and diamond gradients, editable in the inspector and writable by agents. Components can be grouped into a component set with enumerated variant properties and switched from the instance inspector while keeping geometry, property values and name-path overrides. The export dialog writes PNG 1×/2×/4× and optional SVG into one ZIP archive and remembers the settings. The `.sqraft` format moves from 9 to 10 (gradient paints and component sets); 0.0.8 cannot open files saved by 0.0.9. Tool count goes from 33 to 35.

这一版把「交付链」一次补齐：SVG 出、SVG 入、原生渐变、组件变体与导出矩阵。文件格式从 9 升到 10，0.0.8 打不开本版保存的文件。

### SVG 导出

- 右键 `Copy as ▸ SVG`、文件菜单 `Export as ▸ SVG`（`⌘⇧E`）与 agent `export_as({format:"svg"})` 共用同一套序列化
- 形状 / 路径 / 文本 / 图片 / 效果 / 蒙版按矢量输出；文本逐行定位，导入字体内嵌
- 线性与径向渐变保持矢量；角度与菱形渐变、背景模糊、部分效果节点栅格化，清单进 `rasterized`
- 页面导出只画该页，不含根级母版与组件集合

### SVG 导入

- 把 `.svg` 拖进画布即导入为原生节点（按住 `⌥` 拖入则按图片资源插入）；文件菜单与大图拖放同一入口
- 支持 `rect / circle / ellipse / line / polyline / polygon / path / text / g / 本地 use`、纯色与线性/径向渐变、data URI 图片
- 样式按 SVG presentation attributes 继承（`fill / stroke / stroke-width / font-*`，含 `currentColor`）；多子路径线稿拆成多条 path，带填充的多子路径整元素栅格化
- 插入真实 DOM 前会净化克隆（丢弃 `script / foreignObject / iframe / on* / 外链 href / 外链 url()`），不执行、不发起外部请求
- 不支持的子树（`filter / mask / pattern / clip-path` 等）逐元素栅格化成图片贴回原位，不再整份失败；单文件 5MB、3000 节点、200 个栅格化元素上限
- 文本与图片带旋转/缩放时同样走逐元素栅格化，避免丢变换
- 一次导入 = 一个撤销步；agent 用 `import_svg({svg, pageId?, x?, y?})`，返回 `{frameId,width,height,rasterized,missingFonts}`

### 原生渐变

- `fill` / `stroke` 新增 `linear / radial / angular / diamond` 四种渐变；坐标相对节点包围盒（0–1），节点移动缩放时跟随
- 检查器新增结构化渐变编辑器：类型、角度、中心与半径、2–16 个色标（位置、颜色、增删）
- 色标颜色可以引用 Token；Token 严格模式下 agent 写字面色标会被拒绝（`TOKEN_REQUIRED`）
- agent 的 `create_node` / `update_node` 接受 `fillGradient` / `strokeGradient`，优先级为 Token > 渐变 > 字面量

### 组件集合与枚举变体

- 选中 2+ 根级主组件 → 右键「组成组件集合」；组件名必须是 `Property=Value`（如 `Size=M, Type=Primary`），同名属性合并成枚举
- 组件面板按「集合 → 变体」两级展示，单击定位、双击插入实例；集合行尾「+」复制最后一个变体并取一个空闲值
- 实例检查器新增「变体」区块：每个属性一行下拉，不存在的组合置灰
- 切换变体保留实例几何、`propValues` 与按图层名路径匹配的节点覆盖；新变体多出的图层用默认值
- 集合检查器可重命名属性/值、复制或删除变体；有实例引用的变体禁止删除（命令层拦截）
- agent 新增 `create_component_set` 与 `add_variant`；`set_instance_prop` 的属性 id 命中变体属性时等价于切换变体

### 导出矩阵

- 文件菜单「导出…」对当前目标（选区，缺省活动页）一次导出 PNG 1×/2×/4× 与可选 SVG，打成一个 ZIP 压缩包
- 文件名统一为 `<文档>-<页面名>-<对象名>`（整页导出只到页面名，多选也只到页面名）；ZIP 内文件平铺在根目录
- 保存对话框记住上次位置，PNG 只存储不重复压缩
- 设置持久化；不做多目标、PDF、HTML、React 或 Copy as code

### 升级说明

- `.sqraft` 的 `formatVersion` 从 9 升到 10：`Paint` 增加渐变形态，根节点增加 `componentSet`。**0.0.8 无法打开 0.0.9 保存的文件**，请先升级再打开新稿
- 旧文件无需迁移：新增字段全部可选，纯色与原有组件不受影响
- MCP 工具数 33 → 35（`create_component_set` / `add_variant`）；工具清单与 `read_document` 的 document 视图已带上组件集合摘要
- 已知限制：组件名解析不做模糊匹配，命名不合规会直接拒绝；角度/菱形渐变在 SVG 里是栅格化的；SVG 导入的纯文本定位以行盒为准，复杂排版文字会降级为图片

### 手点清单

- 打开多页稿：选区导出 PNG 1×/2×/4× + SVG，确认目录记忆与文件数提示
- 导出一份含线性/径向渐变的稿：SVG 与 PNG 视觉一致；角度/菱形渐变在 SVG 里是位图
- 拖入含 `filter`、渐变、文本的 SVG：可编辑节点正确落下，降级元素有提示，一次撤销全撤
- 两个 `Property=Value` 组件 → 右键组成集合 → 插入实例 → 切变体 → 确认尺寸与覆盖保留；删除有实例的变体应被拒绝
- agent：`create_component_set` → `add_variant` → `set_instance_prop` 切变体；严格模式下写渐变字面色标应报 `TOKEN_REQUIRED`
