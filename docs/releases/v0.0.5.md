## 0.0.5

*English summary:* Large documents are usable now. Opening a 1.5 GB, 554-page, ~195k-node design takes about 3.4 seconds instead of 7–11, scrolling drops from 51 stuttering frames per 120 wheel events to 2, and dragging while zoomed out goes from 408 ms to 30 ms per frame. Page labels disappear below 25% zoom, two offscreen-layer bugs are fixed, and macOS builds are now signed with a Developer ID and notarized, so the first launch no longer needs a Gatekeeper workaround.

几百页的大稿终于能顺着手感用了：打开更快、滚动不卡、缩到全局拖动也跟得上。macOS 包从这版起签名并公证，首次打开不再需要右键或 `xattr` 放行。

### 性能：大文档

实测文档：1.5 GB、554 页、约 19.5 万节点、555 张图（M1 Pro）。

- **打开**：读取 + 传输 + 解析从 7–11 秒降到约 3.4 秒
  - 文件不再整块经 IPC 结构化克隆，主进程登记一次性只读取件地址，渲染层流式读取
  - zip 里本就未压缩的图片条目零拷贝取出，`doc.json` 交给原生解压
- **滚动**：120 次滚轮里超过 50ms 的卡顿帧 51 → 2，回滚已看过的区域 0 帧；滚动时 GPU 平均占用 75%（峰值 94%）→ 46–54%
  - 页面与根级母版的整块合成结果跨帧缓存，平移时直接回贴位图
  - 效果层（投影 / 图层模糊 / 内阴影）与蒙版层同样缓存；背景模糊不缓存（它取样的是下面已画好的内容）
  - 图片按屏幕上实际需要的分辨率分级解码，解码缓存改按最近使用淘汰，滚动时不再反复淘汰重解
- **缩小看全局**：4% 缩放下拖动单帧 408ms → 30ms，缩放手势 15–16ms；停下 150ms 后分帧补清晰
- **视口剔除**：屏幕外的页面 / 母版整棵子树直接跳过；只在根节点这一级判定，成本与文档总节点数无关
- 导出的 PNG 与 AI 截图不受这些缓存影响，仍是逐层完整绘制

### 改进

- 缩放到 25% 以下时，页面与母版的名称标签不再绘制、也不参与命中，避免固定屏幕尺寸的标签互相重叠、遮挡内容；选中的节点仍保留标签（#2）

### 修复

- 半透明分组里的蒙版滚到屏幕边缘时被裁错位置、内容整块消失（嵌套离屏层取错了坐标矩阵）
- 离屏层外接框带小数导致回贴时被拉伸、边缘发糊

### macOS 签名与公证

- macOS 包用 Apple Developer ID 签名并送 Apple 公证，首次打开不再出现「无法验证开发者」；README 里的右键 / `xattr` 放行说明随之删除
- 自动更新在替换前校验新包的代码签名与 Team，校验不过就保留旧版本，不会把坏包装上去
- **从 0.0.4 自动更新上来的那一次仍由旧版（未签名）执行替换**，更新完成后才进入「无提示」状态；想立刻生效就直接下载 dmg 覆盖安装

### 兼容性

- 文档格式不变（`formatVersion` 仍是 8）：0.0.4 与 0.0.5 可以互相打开，本版没有新增字段
- 数据目录、快捷键、已有文档的样式与排版均无变化
- 缩放手势中与刚缩放完的几帧会短暂看到发虚的页面，随后逐帧变清晰——用「缩放时略糊」换「缩放时不卡」

## 安装提示

### macOS

签名 + 公证后双击即可打开，不需要右键、也不需要执行 `xattr` 命令。唯一例外是从 0.0.4 自动更新上来的那一次（见上）。

### Windows

安装器仍未签名，首次运行 SmartScreen 会拦一下：点「更多信息 → 仍要运行」。
安装向导默认按当前用户安装，不需要管理员权限，可在向导里改安装目录；卸载不删 `%APPDATA%\Sqraft`。

## 已知限制

- 安装包只覆盖 macOS Apple Silicon（arm64）与 Windows x64；Intel Mac、Windows ARM64 与 Linux 暂不支持
- 自动更新只在 macOS 上提供；Windows 只提示有新版本，安装包需要手动下载覆盖安装
- 大文档第一次滚入一片没看过的区域仍可能有一两帧偏慢（整块缓存首次合成）
- 缩到很小时，屏幕上不到半个设备像素的点与细线不再绘制（导出不受影响）
- 中日韩文字使用各系统自带字体，同一文档在 macOS 与 Windows 上换行位置可能不同
- 日文 / 韩文文案由 AI 起草并抽查，可能不是母语级润色
