## 0.0.8

*English summary:* This release makes agent setup a first-class part of the app. The MCP panel can now write the Sqraft entry into six clients (Claude Code, Codex, OpenCode, Cursor, VS Code, Zed), back up the file first, read the result back, and follow the port if it drifts. A `⌘K` command palette covers commands, pages, layers, tokens and recent files. Three built-in examples and three copyable prompts make the first agent session concrete. Settings are now consolidated into one window with four sections (General / MCP / Shortcuts / Advanced) reachable by ⌘, and deep links from the old entry points. The `.sqraft` format is unchanged (still 9); tool count is unchanged at 32. Windows one-click setup is implemented but not verified on a real machine yet.

这一版把「接入」从手写配置变成产品的一部分，并给 ⌘K 一个统一入口；文件格式与工具数量都不变。

### MCP 一键接入

- 配置面板列出 **Claude Code / Codex / OpenCode / Cursor / VS Code / Zed** 六个客户端，四态显示：已连接 / 已写入 / 未接入 / 未检测到
- 写入只碰名为 `sqraft` 的那一条：写前备份到 `userData/mcp-backups/`（每客户端保留 5 份）、临时文件 + rename、写后回读校验，失败自动还原
- 每个客户端只有一条写路径：Claude Code / Codex 走官方 CLI（显式 user scope），其余走文件 adapter；JSONC 用范围编辑保留注释
- 端口漂移时只同步所有权清单里的条目；失败保留旧地址并在面板显示「需要处理」，不阻塞启动
- 认不出的同名条目一律不动，由用户在面板里显式「替换」；删除只删自己那条
- 手动片段仍保留（六个客户端 + 通用 URL），CLI 缺失或配置不可写时自动降级为复制
- **Windows**：一键接入已实现，但本版未在 Windows 实机验证；失败时请用面板里的手动片段

### ⌘K 命令面板

- 五类结果：命令、页面、图层、Token、最近文件
- 命令与菜单、快捷键共用 `shared/commands.ts` 的 55 个 id（含设置聚合新增的 `app.shortcuts` 与日食示例命令）；面板里直接显示快捷键
- 图层 2 个字只搜当前页，3 个字起扩到全文档；输入防抖 80ms
- Token 结果跳到设计系统面板并短暂高亮
- 纯键盘可用：`↑↓` / `PageUp` / `PageDown` / `Home` / `End` / `Enter` / `Esc`

### 设置聚合

- 「设置…」（⌘,）改成四个分类：通用（语言）/ MCP / 快捷键 / 高级（数据目录、日志目录、清空图片缓存）
- 旧的「配置 MCP…」、欢迎页按钮、工具栏键位图标与 `⌘/` 都改为"打开设置并跳到对应分类"，再按一次入口关闭
- 「关于」保持独立面板，数据目录移到「高级」
- 键位表补上此前漏显示的 `file` 组 7 条（⌘N / ⌘O / ⇧⌘I / ⌘S / ⇧⌘S / ⌘⇧E / ⌘W）
- 设置里切换分类不会重跑 MCP 客户端检测；需要刷新时用面板里的重新检测

### 示例与引导

- 欢迎页新增三个内置示例：登录页、三列卡片列表、日全食主题落地页（纯图形与文本，无 Token、无图片）
- 日食页演示深色底与效果近似的光晕：文档模型没有渐变，光晕用低透明度椭圆 + 图层模糊/投影还原
- 示例以未保存文档打开，`⌘S` 时才另存
- MCP 面板「连上之后试试」给三条可复制 prompt：批量建卡片、Token + 严格模式、按诊断修复

### 升级说明

- `.sqraft` 的 `formatVersion` 仍是 9，0.0.8 与 0.0.7 文件互相兼容
- 之前手工写进客户端的 `sqraft` 条目会被识别为「已写入」；点「断开」只删这一条
- 新增依赖仅 `jsonc-parser`（devDependency，由 Vite 打进 `out/`，不进 asar 依赖树），不改变安装包外的文件布局
- 配置写入失败不会影响应用启动；日志里能看到 `client ...` 事件
