## 0.0.3

*English summary:* Japanese and Korean UI, per-language CJK font stacks, Japanese line-breaking rules, a relocated MCP menu entry, and English-only errors for MCP agents.

新增日本語 / 한국어 界面，并让画布字体随界面语言切换。

### 新增

- 界面语言支持 中文 / English / 日本語 / 한국어，可选「自动」跟随系统语言
- 设置面板里的语言选项改为纵向列表，切换后立即生效
- 按界面语言选择 CJK 字体栈：日文用 Hiragino / Yu Gothic，韩文用 Apple SD Gothic Neo / Malgun Gothic，避免汉字显示成中文字形
- 新建文本的默认字体跟随当前界面语言

### 改进

- 日文换行加入轻量禁则：行首不出现收尾标点，行尾不留开括号
- 「配置 MCP…」入口移到「设置…」旁边（macOS 在应用菜单，其他平台在文件菜单），帮助菜单不再保留
- MCP 返回给外部 agent 的错误统一为英文，不再把内部错误码直接暴露给 agent
- 核心错误提示支持四语言本地化；未知错误回退到通用文案，原始信息只写入日志
- 检查器里的字体预设随语言变化，不再固定为中文回退字体
- 修正空文本测量与空格断行在日文下不符合禁则的问题

### 兼容性

- 已有文档的文字样式不受影响：文档里记录的 `fontFamily` 不会被改写
- 文件格式、快捷键、数据目录均无变化

## 安装提示（未签名）

首次打开若提示「Sqraft 已损坏」，不是文件损坏，是 macOS Gatekeeper 拦下了未签名应用。
把 App 拖进「应用程序」后执行：

```bash
xattr -dr com.apple.quarantine /Applications/Sqraft.app
```

再打开即可。之后的版本由应用自己下载更新，不会再触发这一步。

## 已知限制

- 仅提供 macOS Apple Silicon（arm64）安装包
- 未签名、未公证，首次打开会被 Gatekeeper 拦截
- 日文 / 韩文文案由 AI 起草并抽查，可能不是母语级润色
- 日文禁则只覆盖行首标点与行尾开括号，未实现完整的 JIS X 4051
