# 参数化多边形：边数 + 包围盒推导

三角形工具需要一种「形状跟着参数走」的表示。候选：三点闭合 `path`、独立 `triangle` 类型、参数化 `polygon`（`sides` + 包围盒）。选择**参数化 `polygon`**：`NodeType` 里已经预留了 `polygon`，三角形只是 `sides: 3` 的一个实例，之后五边形/六边形不需要新类型、新渲染分支或新 AI 工具。

```ts
interface DocNode {
  // …
  /** 仅 polygon：3–12，顶点由包围盒推导 */
  sides?: number;
}
```

## 规则

- **几何由包围盒推导**：`polygonPoints(sides, width, height)` 先算顶点朝上的正多边形单位坐标，再把 X/Y 各向拉伸到撑满包围盒。因此**包围盒就是可见形状的外接矩形**——选中框、缩放手柄、检查器 W/H 与视觉永远一致，不会出现「框比形状宽一圈」。
- **边数夹紧**：`clampSides` 取整并夹到 3–12，非法值回落为 3。命令层在 `node.create` / `node.update` 统一夹紧，GUI 与 AI 共用同一规则，检查器只负责展示。
- **三角形 = `sides: 3`**：工具条「三角形」（`G`）创建 `polygon` + `sides: 3`，默认名「三角形 N」、填充 `color/primary`；其它边数默认名「多边形 N」。检查器类型标签跟着边数走。
- **拖拽创建**：角对角拖出包围盒，拖拽中直接画真实多边形轮廓；`⇧` 锁正三角形比例 `1 : √3/2`（以拖动更长的方向为基准）。
- **不是路径**：多边形没有锚点，双击 = 普通选中，不进锚点编辑；顶点由参数决定，不做逐点编辑。
- **不做圆角**：多边形圆角要按边长与转角算上限（半径过大时形状自交），本轮不实现；需要时先「转换为路径」再走路径的圆角/锚点编辑（后续单独设计）。
- **命中按几何**：有填充时内部可点，无填充时按描边距离（5px 屏幕容差）；与 `path` 共用同一容差策略，避免多边形包围盒的空白区域抢点击。
- **渲染**：`RenderBackend.drawPolygon(node, points, …)` 接收节点本地顶点，Canvas 2D 后端负责平移与旋转；缩放只改 W/H，顶点下次绘制时自动重算。

## Consequences

- 三角形不是独立节点类型：图层/检查器按 `sides` 显示「三角形 / 多边形」，文档里只有 `polygon`。
- 缩放、旋转、移动、撤销、AI 都复用现有节点机制，无需为多边形写特殊命令。
- 三角之后做任意多边形工具时，只需要加一个工具入口与「边数」默认值，几何/渲染/命中/AI 全部现成。
- 星形（`star`）仍在 roadmap 待补；它需要内外半径两个参数，不能直接复用 `sides`。
