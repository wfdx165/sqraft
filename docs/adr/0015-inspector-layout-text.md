# 0015 检查器、自动布局与文本排版模型

日期：2026-10-29

## 背景

检查器只覆盖了部分真实生效的字段：自动布局只写 `layout` 不参与求解；填充/描边下拉混入 number Token；文本面板只有字号与文案；旋转、不透明度、可见、锁定没有入口；分组可改宽高会破坏并集。本轮按 Figma 对齐补齐，并落地完整自动布局与文本面板。

## 决策

1. **自动布局在命令层求解并写回几何**：事务末尾自底向上求解受影响的容器链，结果作为内部 `node.update` 与用户命令共用一个撤销条目；文档几何仍是唯一真源。
2. **子项布局字段放在子节点上**：`layoutSizingW/H`、min/max、`layoutAbsolute` 随节点移动与覆盖，不做容器侧 childId 映射。
3. **padding / 圆角存四边四角对象**：统一值是 UI 快捷，不做联合类型。
4. **文本整段单一样式**：完整 Figma 文本面板但不做逐字符 runs；测量留在 UI 层，core 只消费尺寸。
5. **锁定在用户命令入口校验**：锁定整棵子树，系统同步/布局写回/撤销重做豁免，避免锁死历史。
6. **颜色允许 UI 字面量**：Token 仍是默认入口，自定义 hex 支持 8 位 alpha；AI 工具继续只接受 Token。
7. **迁移链**：`formatVersion` 升到 2，`migrateDoc` 按版本顺序归一化字段；旧文档 `clip=false` 保持外观。

## 后果

- 布局容器内的手动几何不再有效，拖动改为重排；缩放自动转 fixed。
- 渲染层需要支持容器旋转变换、四角圆角、裁剪与透明度。
- 文本换行、列表、截断的绘制与测量必须共用同一行盒算法，否则提交后会出现跳动。
- Canvas 2D 无法表达自定义 OpenType feature 与可变字体轴，检查器明确禁用。
