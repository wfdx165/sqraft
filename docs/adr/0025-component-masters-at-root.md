# 主组件是文档根节点，不属于任何页面

主组件原来只能是页面顶层节点（ADR-0014）。这让「组件库」和「设计稿」混在同一棵树里：页面一挪，母版跟着挪；页面导出/截图会带上母版；切页面时母版被淡化；MCP 建的母版默认落在活动页里，看起来像画在设计稿上。

替代方案：把母版放进一个专门的「组件页」——那只是把问题换了个名字，母版仍然是页面的子节点，仍然要处理"删页面要不要连带母版"；或者让母版完全脱离画布、只存在于组件面板——那要额外做一个母版编辑视图，和现有所有渲染假设冲突。

选择：**主组件直接挂在文档根节点上**，与页面平级。

```ts
interface DocState {
  /** 根节点：页面 + 主组件（两类都可能在根上） */
  rootIds: NodeId[];
}
```

## 规则

- **根节点只有两类**：`page` 与 `component`。别的节点挂到根上一律拒绝。
- **主组件只能在根上**：`node.create` 建 `component` 时必须 `parentId: null`；`node.reparent` 不能把主组件移进任何节点。撤销/重做走 `applyOne`，不受这条校验限制，能精确还原历史结构。
- **转组件就地转换**：`component.create` 展开成「reparent 到根（世界坐标）」+「type 改成 component」，画面位置不变；撤销回到原父级。
- **组件区**：新建空白主组件（GUI 与 MCP）排到「页面整体包围盒下方 + 间距」的一行里，从左往右；显式给坐标时照办。
- **绘制顺序**：先画所有页面，再画所有根级主组件——母版永远浮在页面之上（即使坐标落在页面矩形内）。
- **命中**：根级主组件先于页面命中；`Hit.pageId` 只是"当时的活动页"，命中母版不会切页。
- **页面操作不再牵连组件**：删页面不动母版；导出页面、截页面都不含母版。删除母版仍然让引用它的实例脱离（原规则不变）。
- **左栏只有页面**：母版不进页面图层树，只在「组件」tab 里平铺列出。面板里单击 = 选中并飞行定位，双击/行尾「+」= 插入实例（单击不再插入，避免浏览时误产实例）。
- **缩放适配**包含组件区，否则母版会看不见。

## AI 接口

- `create_node(kind=component)` 不接受 `parentId`；省略 `x/y` 时自动排到组件区。
- `read_document` 顶层给 `components` 摘要，`includeComponentTrees=true` 时附带母版子树。
- 新增 `move_node` 补上「换父级」这个缺口（等价画布拖动，自动布局容器默认进流）。

## 代价

- `rootIds` 不再是"页面列表"：所有读它的地方都要按 `type === "page"` 过滤（`getPages` 已经统一）。
- 老文件不做迁移：项目还没有历史文件，遇到旧结构视为已废弃。
