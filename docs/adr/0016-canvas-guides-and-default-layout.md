# 0016 容器内参考线与新建容器默认自动布局

日期：2026-10-29

## 背景

参考线此前只服务页面拖动：`pageDragContext` 只收页面矩形，`guides.ts` 的注释也写明“普通图层不参与”。画板内部画画、拖拖全靠目测，间距要开检查器猜。同时自动布局是手工开启的可选能力，新建画板默认是自由画布。

## 决策

1. **参考线按父容器建上下文**：目标 = 同父兄弟 + 父内容区（padding 内框）+ 父边界；跨父容器多选不出线。
2. **几何统一用 `worldRect` 的 AABB**：旋转节点也用包围盒；修正量以世界位移直接写回本地 `x/y`。
3. **拖动、绘制、缩放共用同一套吸附**：绘制只吸指针那一角，缩放只吸被拖动的边，`⇧` 等比时不吸。
4. **锁定节点仍是吸附目标，隐藏节点不是**：锁定常用于“底板别动、其他贴着排”。
5. **`⌥` 临时关闭吸附**：不修正偏移也不画线（钢笔的断链语义只在钢笔模式内，不冲突）。
6. **新建 `frame` / `component` 默认带自动布局**：纵向、gap 10、padding 10、尺寸 fixed；只作用于新建入口，不迁移历史文档。
7. **默认必须可退出**：检查器保留“移除布局”，移除后子项保持当前几何。

## 后果

- 画进布局容器的节点会被重新排布：按落点投影算插入索引，想自由摆放需 `⌘`/检查器转绝对定位。
- 拖动中不再显示尺寸徽标（间距标签会与它重叠）；尺寸在检查器与缩放时可见。
- 页面参考线改走同一套上下文（父容器为空时候选即其它页面），行为保持。
- 参考线只在拖动/绘制/缩放期间存在，没有常驻模式，也没有“显示参考线”开关。
