# 纯单机：文件系统优先，无后端无账户

Sqraft 没有服务器、账户与云同步。设计稿以 `.sqraft` 文件形式存在于用户磁盘，通过 File System Access API 直接打开/保存并自动写回；Safari/Firefox 降级为下载导出/上传导入。这是产品决策（Q1=轻量、Q7=纯单机、Q5=个人项目）与技术形态的统一，不是临时简化。

## Considered Options

- IndexedDB 应用内文档库（Figma Drafts 心智）：体验顺滑，但数据"锁在浏览器里"，与"单机程序"的心智承诺冲突，且清理浏览器数据即丢稿。
- 双轨（IndexedDB + 文件系统同步）：双真源同步是单人项目的经典陷阱。

## Consequences

- 文件格式必须自包含（图片、嵌入字体进包），不引用本地外链。
- "最近打开"只存文件句柄（有权限时）或路径提示，不存数据副本。
- 若未来做桌面壳（Tauri/Electron），文件层直接换系统对话框，命令层不受影响。
