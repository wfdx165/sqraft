# 组件系统：物化实例 + 插槽 + 字段级覆盖

组件需要同时解决「复用」和「可替换内容」。候选：纯引用（实例只存 componentId，渲染时解析）、快照副本（插入即独立副本）、物化子树（实例持有真实节点 + `mainId` 映射）。选择**物化子树**：现有渲染、命中、`worldRect`、文本编辑、AI 读文档都假设「文档里是真实节点」；纯引用会要求每个消费方多一层合成节点分支，快照副本则无法同步。

```ts
interface DocNode {
  // …
  /** 主组件：组件接口 */
  propertyDefs?: ComponentPropertyDef[];
  /** 实例 */
  componentId?: NodeId;
  mainId?: NodeId;                 // 当前母版里的身份；实例根 = componentId
  propValues?: Record<string, string | boolean | NodeId>;
  overrides?: Record<NodeId, NodeOverride>;
  /** 插槽实例侧：默认内容是否已被替换 */
  slotFilled?: boolean;
}
```

## 规则

- **主组件在页面顶层**：`component` 必须是页面的直接子节点；组件里只能放实例，不能放组件。
- **确定性物化**：实例根 id 由调用方在命令前生成；子孙 id 为「父节点 id + 母版节点身份键」；同一实例重复物化得到相同 id。同步执行期禁止 `newId()`/时间/随机。
- **同一撤销步**：母版更新、实例重建、覆盖表维护、删除级联都在一个 `apply` 内完成；一次撤销同时回退。
- **同步按依赖拓扑序**：A 里放 B 的实例时，先同步 B，再同步 A；级联有环在创建/插入/替换入口拒绝。
- **字段级覆盖**：编辑实例内部字段时自动按 `mainId` 比对母版，写入 `NodeOverride`；改回母版值即删除。`style` 可只覆盖子字段。属性绑定的字段不写覆盖。
- **属性优先**：文本/布尔/实例替换属性的值以 `forced` 参与同步，优先于覆盖与母版；属性有稳定 id，改名不影响值。
- **插槽替换语义**：具名、组件内唯一、可带默认内容；实例首次填充整体替换默认，清空恢复默认；已填充插槽内容不参与母版同步。
- **替换与脱离**：替换保留位置、尺寸取新组件、同名已填充插槽内容保留；脱离为 `frame`，插槽转画板、空槽删除、嵌套实例保留。
- **删除规则**：删除主组件或含组件的页面时，引用它的实例先自动脱离；删除已填充的母版插槽直接拒绝。

## Consequences

- 文档比纯引用大：实例子树是真实节点；换来所有现有编辑/渲染/命中/文本/AI 路径零改造。
- 同步与覆盖维护集中在命令层，GUI 与 AI 自动一致；代价是必须守住确定性 id 与同一条撤销步。
- 本轮只交付文本、布尔、实例替换属性；枚举属性与变体（组件集合）、跨文件组件库、作用域插槽仍未交付。
- 画板渲染改为尊重样式（有填充才画底色），脱离后的实例不会凭空多出白底；画板工具新建仍默认 `color/surface`。
