# 无限画布：所有页面同屏、自由摆放

此前页面是互斥的"当前页"——画布一次只显示一页，切换靠左栏。产品复盘后改为无限画布形态：所有页面都摆在画布上，滚动/缩放浏览；页面是带固定尺寸的白色画板（默认 1440×1024），携带 `x/y/width/height`，可以自由拖动；新建页面放到最右侧页面之右（间距 160）。

左栏页面列表保留为导航（点击飞过去并展开图层），不再有"当前页"概念。绘图工具只允许画在页面内（按拖拽起点归属），页面外不允许创建；AI 工具默认第一个页面，可用 `parentId` 指定。

## Consequences

- 渲染与命中检测必须按祖先链累加容器偏移（`worldRect`），子节点坐标相对父容器的约定因此成为硬约束。
- 页面删除不再"自动重排"其他页面（自由摆放语义），列表与画布可能出现位置与顺序不一致，属预期。
