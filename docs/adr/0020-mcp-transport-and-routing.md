# MCP 接入：本机 IPC、薄 CLI 与工具路由

> **已被 ADR-0026 取代（2026-10）**：传输已改为本机 Streamable HTTP，薄 CLI 已删除。本篇保留作为当时决策的对照。

外部 agent 通过 MCP 驱动 Sqraft。实现刻意不用 SDK：协议面只需要 `initialize` / `tools/list` / `tools/call` / `ping`，自己实现比适配传输层更短、更好测。

## 链路

- 主进程跑 MCP server，端点为 `userData/mcp.sock`（macOS/Linux）或 `\\.\pipe\sqraft-mcp`（Windows）。
- 随应用分发一个零依赖的薄 CLI：只做 `stdio ↔ 本机 IPC` 双向管道。连不上时先拉起应用（`--mcp`，跳过欢迎页直接建空稿），再 attach。
- agent 杀掉 CLI 只影响管道，不影响应用与未保存的文档——这是 CLI 与"App 自己吃 `--mcp`"的关键区别。
- 连接建立先做 hello 握手（协议版本 + 应用版本），不兼容返回可读错误。

## 工具路由

- 工具清单与执行器都在渲染进程（`@sqraft/ai-tools` 是唯一真源），主进程只转发一次 IPC 往返。
- 主进程不持有文档状态；MCP 调用与 GUI 走同一条命令路径与校验。
- 截图由渲染层离屏重绘文档层（不含网格、选中框、参考线），支持文档坐标下的 `region` 裁剪；结果以 MCP `image` content 返回。
- `document.open` 只触发系统对话框，**不接受路径参数**——agent 不能借工具读任意磁盘文件。

## 并发与错误

- 多客户端并存，所有调用进**同一串行队列**：先到先执行，避免两个 agent 交错读写。
- **超时只对调用方生效**：30s 到点给客户端回结构化错误，但任务本身撤不回来，所以队列要等它真正结束才开始下一条。提前放行下一个调用会让两个工具同时改文档，而 `DocStore.transact` 只有一个事务槽，会把两个调用并成一条撤销记录。
- 代价：某个调用卡在用户交互上（`document.open` / `document.new` 的系统对话框）时，队列会一直等，其他 agent 的调用排队——这是刻意的，文档正在被用户处置时不该被第二个 agent 改。
- 连接断开时丢弃该连接排队中的调用；应用退出前广播 `sqraft/shutdown`。
- 工具异常映射为 `isError: true` + 文本原因，不用 JSON-RPC 错误码，客户端能直接读。

## 撤销粒度

一次工具调用里的多条命令经 `DocStore.transact` 合并成**一条**撤销记录（标签 `MCP：<工具名>`）；事务失败时回滚，文档不会停在半成品状态。

## 日志

操作日志只写终端，格式固定为 `[mcp] HH:mm:ss.SSS <级别> <连接号> <身份> <事件> <字段>`：info/warn 进 stdout，error 进 stderr。

- **不落文件、不用 `console`**：v1 的故障都是"还原一次调用"，连着终端看就够；落文件要连带轮转、保留与路径暴露，收益不抵成本。写入口可注入，测试据此静音。
- **参数只记摘要**：长字符串截断、`data:image` 折叠成类型与体积、整行兜底 1KB；规则单点在 `src/main/mcp/log.ts`，埋点处只给事件与字段。
- **身份来自 CLI**：hello 里附带 `pid` / `ppid` / 父进程名（`ps`，取不到就降级为 `pid=`），字段可选，旧 CLI 不带也能连。app 侧拿不到对端信息，只有 CLI 知道自己是哪个 agent 拉起来的。
- **不做级别开关**：排队超过 1s 才记 warn，噪音靠阈值挡，不靠多一档级别。
- **所有字符串都过同一套单行化**：事件文本、连接身份、参数摘要都会压平换行，并把控制字符（含 ESC）转义成 `\uXXXX`。连接方自报的 `name`、工具名都是不可信输入，不能让它们伪造日志行或把转义序列送进读日志的终端。

代价：打包版从 Finder 启动时 stdout 没有出口，日志看不见；需要排查时从终端启动应用。

## Consequences

- 应用必须运行（或由 CLI 拉起）才能服务 MCP；没有"无头模式"。
- 协议面是自实现的，新增 MCP 方法需要自己补；这是为了避免 SDK 与 Electron 打包/传输适配的长期摩擦。
- 工具名不加 `sqraft_` 前缀，命名空间由客户端展示层提供；新增能力必须同时有 GUI 入口（ADR-0004）。
