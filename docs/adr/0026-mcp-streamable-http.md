# MCP 接入：本机 Streamable HTTP（删除薄 CLI）

> 取代 ADR-0020。外部 agent 仍然通过 MCP 驱动 Sqraft，但传输从「Unix socket / 命名管道 + 薄 CLI」换成**本机 HTTP**。

## Context

ADR-0020 的链路是：主进程在 `userData/mcp.sock` 上自实现换行分隔 JSON-RPC，随应用分发一个 `sqraft-mcp` 薄 CLI 做 `stdio ↔ socket` 管道，连不上时拉起应用。

实际使用里这套链路的成本集中在三处：

- 接入要先安装 CLI / 建软链，再写 `command/args`；对只想要「填一个 URL」的客户端来说是不必要的摩擦；
- CLI 与主进程各有一份端点规则，改名、打包、PATH 权限每一件都出过问题；
- 自定义 `hello` 握手与 `ping/pong` 心跳是自己发明的协议面，客户端无法复用规范行为。

## Decision

- **传输**：规范 MCP Streamable HTTP。单端点 `POST /mcp`，支持 `2025-11-25` / `2025-06-18` / `2025-03-26`；请求更老的版本时按规范回落到最新受支持版本（由客户端决定是否继续），不报错。后续请求的 `MCP-Protocol-Version` 头缺失按 `2025-03-26` 处理，非法值返回 `400`。
- **会话**：`initialize` 成功时下发 `Mcp-Session-Id`；会话空闲 30 分钟过期；`DELETE /mcp` 主动结束；未知/过期会话返回 `404` 让客户端重新握手。会话标签取 `initialize.params.clientInfo`（如 `c1 claude-code/2.1`）。**界面上"在线"= 最近 2 分钟有请求的会话**——HTTP 没有连接，探测型会话（`mcp list`）会因此很快从计数里消失；详情浮层最多列 5 条，其余只显示数量。
- **不提供 SSE**：`GET /mcp` 一律 `405`；`POST` 直接回 `application/json`。没有 `sqraft/shutdown` 推送——应用退出时客户端下一次请求会失败，这是可接受的。
- **端口**：默认 `7331`。显式端口（用户在配置面板填写）严格执行，被占即报错；自动模式被占时向上顺延（最多 20 步）、把实际端口写回偏好，并在界面上明显告警。范围 `1024–65535`。
- **安全**：只绑 `127.0.0.1`；拒绝任何带 `Origin` 的请求（防浏览器 DNS rebinding）；`Host` 只接受 `127.0.0.1` / `localhost` / `[::1]`。**没有 token**：同机其他进程与用户也能连，这是有意的取舍。
- **删除 CLI**：不再分发 `sqraft-mcp`，不再支持"应用没跑时由 CLI 拉起"。启动时用 `inspectEntry()` 识别并删除指向本应用旧 CLI 的软链（`current` / `stale`），`foreign` 一律不碰。
- **不变**：工具清单与执行器仍在渲染层（`@sqraft/ai-tools` 唯一真源）；全局串行队列、单次 30s 超时、一次调用一条撤销、首次调用自动建空稿。

## Considered Options

- **保留 socket + CLI**：继续维护两份端点规则与自定义握手，接入摩擦不变。否决。
- **CLI 内部改成 HTTP 客户端**：用户配置可以不改，但"不装东西"的收益推迟一版，还多养一版一次性代码。否决。
- **监听 `0.0.0.0` 支持远程**：需要引入 TLS、鉴权与防火墙说明，与"纯单机"定位冲突（ADR-0004 / ADR-0019）。否决。
- **每次启动随机端口**：URL 会漂移，而客户端配置是手写且长期不变的。否决。
- **持久 Bearer token / URL 内嵌 secret**：能挡住同机其他用户，但让配置从"一个 URL"退回"URL + header"，与本次目标冲突。否决。

## Consequences

- **应用必须保持运行**，否则客户端连不上；不再有"agent 一调工具就把 Sqraft 拉起来"的体验。
- 同机任意用户/进程都能连接端点并修改当前文档；共享机器上这是相对 socket 的退步，文档里必须写明。
- 客户端配置一次之后长期有效；只有端口漂移或用户改端口时需要更新，界面负责把新地址显性化。
- 旧 CLI 用户需要把客户端配置从 `command/args` 改成 URL；启动时清理软链，但不改客户端配置。
- 日志不再有 CLI 提供的 `pid/父进程名`，身份改用 `clientInfo` 与连接号；参数摘要与截断规则不变。
