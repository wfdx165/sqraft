# 拖动模式与编辑模式分离

无限画布上"看页面"和"改页面"是两种不同意图。此前它们混在一起：左键既能平移又能移动对象，页面一铺满屏幕就没有空白可拖；检查器与选区也始终处于可编辑状态，容易误改。

改为两个显式模式（`ui.mode`）：

- **拖动模式**：任意处拖动 = 平移；不改变选区、不进入编辑；视图操作全部归这里。
- **编辑模式**：只编辑活动页（`ui.activePageId`），非活动页淡化且不可命中；图层可直接拖动，**页面只能拖名称标签移动**（页面空白处拖动不做任何事）；可缩放图层与页面；不能拖拽平移画布，但滚轮可以滚动（无边界）；缩放锚点固定为活动页中心，避免按钮缩放把内容缩出屏幕。

## Consequences

- 模式是 UI 状态，不进文档、不进撤销；`.sqraft` 文件格式不变。
- 编辑模式的活动页是"UI 当前页"，与 ADR-0007 的"无文档级当前页"一致。
- 从编辑切回拖动会清空选区；再切回编辑沿用上次活动页（无则按选中页 → 视口中心页 → 第一页）。
- 视图的**拖拽**平移与编辑被强制分开；滚轮滚动不属于"平移手势"，两种模式都可用（滚轮改为平移后重新拍板，见 2026-10 修订）。
- 切进编辑模式只在活动页可见面积 < 15% 时自动适配，否则保持当前视图。
- 文本节点不参与缩放手柄（框随文字走），页面/画板缩放不改变子节点尺寸，也不做裁切——裁切留作未来的画板属性。

## 修订（2026-10）

滚轮从"缩放"改为"平移"后，编辑模式"不能平移"的原始理由（内容会被缩出屏幕）不再成立：滚轮位移是有界的视觉移动，且 `⇧1` 一键找回。因此收窄为**不能拖拽平移**，滚轮滚动在两种模式下一致；`⌘+滚轮` 的缩放锚点从活动页中心改为光标（既然已经能滚动，锚在页中心会与光标位置打架），按钮类缩放仍锚活动页中心。

同时把"拖动"的入口收敛到不易误触的位置：拖动模式下**在页面上拖动不平移画布**（页面保持不动，平移只发生在页面之外的空白）；编辑模式下**页面只能靠拖名称标签移动**，页面空白处拖动不再移动整页。视图平移始终可以用滚轮完成，所以不会因为"抓不到空白"而卡住。
