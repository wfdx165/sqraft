# AI 原生打磨（v1 交付前）

**Status:** ready-for-agent

## Problem Statement

工具已经能画、能改、能被 agent 驱动，但离"为 AI 原生而设计的 UI/UX 工具"还差一层：

- 新文件一打开就带着一个 `页面 1` 和四个默认 Token——那是编辑器在替用户决定设计系统；AI 生成时还会在这些默认值上继续叠，稿子越用越脏。
- 页面设了背景色不生效（改了没反应），页面也没法设背景图，做深色页、品牌底、整页大图都得靠拖一张图层硬凑。
- 设计稿没法交出去：不能把选区/页面复制成 PNG，也不能导出文件；agent 只能拿到视口截图，分辨率还跟着当前缩放走。
- 字体只能用 5 个预设栈，换机器就变形；AI 更是连字面量色值都写不了，新文件没有 Token 时它画出来的东西是没有颜色的。
- agent 连接数只增不减，看不出是谁连着、连了多久；开发者排查"自动布局为什么这样排"只能靠肉眼和日志。
- 数据散在 `~/Library/Application Support/Sqraft`，用户找不到；开发态还默认开着调试端口。

## Solution

按五批交付，每批独立可验：

1. **清 bug 与默认值**：页面背景色生效；新文件没有页面也没有 Token（空画布引导卡，绘图工具置灰，agent 自动建页）；新建图形用字面色值，AI 也能写字面量。
2. **小改动**：调试端口默认关闭（保留环境变量开关）；欢迎页标语改为「为 AI 原生而设计的 UI/UX 工具」；agent 连接列表（只读）+ 心跳清理僵尸连接。
3. **图片能力**：`⌘⇧C` 复制选区/页面为 PNG、`文件 → 导出 PNG…` 落盘（默认 2×，页面带底色、选区透明）；页面支持背景图（cover/contain/tile）。
4. **字体与开发者工具**：导入并嵌入字体文件（按 family/weight 归组）；菜单「帮助 → 开发者工具」在开发态直接打开 Electron 自带的 DevTools。
5. **数据目录**：统一到 `~/.sqraft/`，首次启动迁移偏好，socket 路径与 CLI 同步。

## User Stories

### 默认值与空文档

1. 作为设计师，我希望新建文件是空的，这样我不会被一个不是我建的页面和一套不是我定的 Token 干扰。
2. 作为设计师，我希望空文件中央有一张「新建页面」的引导卡，这样我知道下一步该做什么，而不是以为画布坏了。
3. 作为设计师，我希望没有页面时绘图工具置灰，这样我不会画半天才发现落在空气里。
4. 作为设计师，我希望第一次落笔前点一下「新建页面」就得到默认尺寸的页面，这样我不需要填表单。
5. 作为设计师，我希望新画的矩形是主色、画板是白底、文本是深灰，这样第一笔就能看见东西。
6. 作为设计师，我希望这些默认颜色是字面色值而不是 Token，这样我的设计系统由我自己定义。
7. 作为设计师，我希望给页面设背景色立刻生效，这样我能做深色页面。
8. 作为设计师，我希望页面能设背景图并选择 cover/contain/tile，这样我能做整页大图的稿子。
9. 作为设计师，我希望背景图盖在背景色之上、可以被一键清除，这样我不需要删图层。
10. 作为设计师，我希望老的 `.sqraft` 文件打开后外观完全不变，这样升级不会毁掉已交付的稿子。

### agent 与字面量

11. 作为 agent，我希望在空文档里 `create_node` 不需要先建页面，这样我不会卡在"没有页面"上。
12. 作为 agent，我希望可以直接传字面量色值，这样在用户还没建 Token 时也能画出有颜色的稿子。
13. 作为 agent，我希望 `fillToken` 仍然可用且优先，这样用户有设计系统时我依然遵守它。
14. 作为 agent，我希望 `get_tokens` 在文档没有 Token 时返回空表而不是报错，这样我能判断"该不该写字面量"。
15. 作为 agent，我希望 `update_node` 能设置页面背景图，这样我能生成整页视觉。
16. 作为 agent，我希望有 `export_png` 工具，这样我能交付可落盘的图而不是视口截图。
17. 作为 agent，我希望 `export_png` 能指定倍率与是否透明，这样我能按交付要求出图。
18. 作为 agent，我希望有 `import_font` 工具（字节内联），这样我能在用户给的字体基础上排版。
19. 作为 agent，我希望有 `inspect_layout` 工具，这样我能读到自动布局求解后的真实几何，而不是自己推。
20. 作为 agent，我希望布局数据按页面/节点按需取，这样大文档不会把上下文撑爆。

### 交付与导出

21. 作为设计师，我希望选中图层按 `⌘⇧C` 就把它们复制成 PNG，这样我能直接粘进聊天或文档。
22. 作为设计师，我希望没有选区时 `⌘⇧C` 复制整个活动页，这样我能一键交整页。
23. 作为设计师，我希望复制选区时背景透明，这样贴到别处不会多出一块白底。
24. 作为设计师，我希望复制/导出页面时带页面背景色与背景图，这样交付的是完整页面。
25. 作为设计师，我希望导出时能选 1×/2×/3×，默认 2×，这样我能兼顾体积与清晰度。
26. 作为设计师，我希望导出走系统保存框，这样我能决定存哪。
27. 作为设计师，我希望导出的图不含选中框、参考线、插槽占位，这样交付物是干净的。

### 字体

28. 作为设计师，我希望导入本地字体文件（woff2/woff/ttf/otf），这样我不用被 5 个预设限制。
29. 作为设计师，我希望同一字族的不同字重自动归组，这样切字重不会变成换字体。
30. 作为设计师，我希望字重下拉只列出这个字族实际有的档位，这样我不会选到不存在的字重。
31. 作为设计师，我希望导入的字体跟着 `.sqraft` 走，这样换机器打开排版不变。
32. 作为设计师，我希望字体文件超限时有明确提示，这样我不会以为导入成功了。
33. 作为设计师，我希望画布、复制成 PNG、导出文件用的是同一套字体渲染，这样预览与交付一致。

### agent 连接与开发者

34. 作为设计师，我希望点击「已连接 N 个 agent」能看到列表，这样我知道是谁在改我的稿子。
35. 作为设计师，我希望列表显示身份与连接时长，这样我能判断是不是僵尸连接。
36. 作为设计师，我希望断开或异常退出的 agent 会自动从计数里消失，这样数字不会只增不减。
37. 作为设计师，我希望旧版 CLI 连上来时不会被误踢，这样升级顺序不影响使用。
38. 作为开发者，我希望从菜单直接打开 Chrome 那样的开发者工具，这样我能看 console、抓报错、查 DOM，而不用再开调试端口。
39. 作为开发者，我希望开发者工具停在窗口右侧且再点一次就关，这样它不挡左栏页面与右侧检查器。
40. 作为开发者，我希望 DevTools 的快捷键不与编辑器抢键，这样「插入图片」之类的操作不会被顶掉。

### 数据与开发体验

41. 作为设计师，我希望偏好与连接信息存在 `~/.sqraft/`，这样我能在 home 下找到它。
42. 作为设计师，我希望升级后最近文件列表还在，这样欢迎页不会空一半。
43. 作为设计师，我希望迁移失败时旧数据还在，这样我不会因为升级丢配置。
44. 作为开发者，我希望 `pnpm dev` 默认不开调试端口，这样本机不会暴露可被连接的控制端口。
45. 作为开发者，我希望需要时用环境变量把端口开回来，这样只读检查流程还能用。
46. 作为开发者，我希望 CLI 与主进程的端点规则永远一致，这样改了路径不会出现"连不上"。
47. 作为访客，我希望欢迎页说清楚这个工具是什么，这样我一眼知道它面向 AI 原生工作流。

## Implementation Decisions

### 批次与顺序

① 默认值与 bug → ② 调试端口/标语/agent 列表 → ③ 复制与导出 PNG、页面背景图 → ④ 字体导入、开发者工具菜单 → ⑤ 数据目录迁移。每批单独 `pnpm test && pnpm build` 与手点验收。

### 空文档

- `createEmptyDoc()` 不再创建页面，`rootIds` 为空，Token 表为空。
- 画布在无页面时显示引导卡（居中，按钮「新建页面」），按默认尺寸建页；绘图工具、框选、参考线拖出在无页面时不可用。
- agent 工具在文档无页面时自动建一页（与人工建页同一套命令），再执行原操作。
- 老文件不受影响：只有"新建文档"走空文档。

### 默认颜色

- 人手新建：矩形/椭圆/多边形/闭合路径 `#3366ff`，画板 `#ffffff`，文本与开放路径 `#1a1a1a`（描边宽 2）。
- 都是字面色值，不写 Token；用户想用设计系统就在设计系统面板里自建 Token 再引用。

### 字面量纪律（AI）

- `ai-tools` 不再拒绝字面量色值：`fillToken`/`strokeToken` 仍优先，新增 `fill`/`stroke` 字面量入参。
- `get_tokens` 在无 Token 时返回空表并附一句提示；agent 用 `define_token` 自建 Token（同路径同类型覆盖，不允许改类型；颜色接受 #hex 3/6/8 位、rgb/rgba），用 `rename_token` 改名并带走 fill / stroke / 阴影颜色引用。
- `define_token` 的覆盖是 agent 入口的幂等语义；设计系统面板的新增仍拒绝重名（防手滑），两边有意不同。
- 同步 AGENTS 不变式 6 与新增 ADR-0024（纪律从"强制"降为"约定"）。

### 页面背景

- 背景色复用 `page.style.fill`（缺省白）。
- 新增 `page.backgroundImage?: { assetId; fit: "cover" | "contain" | "tile" }`（尺寸以解码后的位图为准，旧文件里的 `natural*` 忽略）；图片进 `.sqraft` 的 `assets/`，按内容哈希命名。
- 渲染顺序：背景色 → 背景图 → 子节点；背景图不参与命中测试、不出现在图层树。
- 检查器「背景」组：颜色在上、图片在下（缩略图 + 适配方式 + 清除）。

### 复制与导出 PNG

- 新增"按倍率离屏重绘"入口：给定区域与倍率，重绘文档（不含 UI 叠加层）输出 PNG；与 MCP `screenshot` 分开，不吃当前缩放。
- `⌘⇧C`：有选区导出选区（透明背景），无选区导出活动页（带页面背景）；写入系统剪贴板为 `image/png`。
- 菜单「文件 → 导出 PNG…」：系统保存框，倍率 1×/2×/3×（默认 2×）。
- 导出包含页面背景色与背景图，不包含选中框、参考线、插槽占位。

### 字体

- 文档新增字体表：`{ family; weight; style; assetId }[]`；字体文件存 `assets/fonts/<hash>.<ext>`。
- 导入支持 `woff2/woff/ttf/otf`；单文件 ≤5MB，单文档字体总量 ≤20MB，超限给可读错误，不静默丢弃。
- 按文件内 family/weight/style 归组；检查器字体下拉列出已导入字族，字重下拉只列该字族实际档位，缺失时回退最近档。
- 渲染注册 `FontFace`，画布、导出、MCP 截图共用同一注册表；导出前等待 `document.fonts.ready`。
- 不做子集化、不做授权校验（导入即视为用户已获授权）。

### agent 连接

- `McpStatus.clients` 由数字改为列表：`{ id; label; connectedAt; lastToolAt?; lastTool? }[]`；徽标数字取列表长度。
- 徽标可点击，弹出只读浮层（身份、连接时长、最近一次工具调用）；不提供断开按钮。
- 心跳：服务端每 30s 发 `ping`，10s 无 `pong` 则 `destroy()` 并刷新计数；握手协商协议版本，旧客户端降级为不发心跳、不因无 `pong` 被踢。

### 开发者工具

- 菜单「帮助 → 开发者工具」打开 Electron 自带 DevTools（`openDevTools({ mode: "right" })`），再点一次关闭；**只有未打包运行（`pnpm dev`）才有这一项**，安装包与 `dist:dir` 产物里不出现，也不留空分组。
- 快捷键：macOS `⌥⌘I`，Windows/Linux `F12`（不用 `Ctrl+Shift+I`：渲染层把 ctrlKey 当 `⌘`，那是「插入图片」）；两个组合进渲染层的保留键表。
- 早先的「布局检查」只读面板按产品决定删除；需要结构化几何时走 `inspect_layout` 工具。

### 数据目录

- 数据根目录改为 `~/.sqraft/`（跨平台同一位置）：`preferences.json`、`mcp.sock`。
- 首次启动：旧目录存在且新目录不存在时复制 `preferences.json`，写 `.migrated-from-userdata` 标记；旧目录保留不删。
- `endpoint.ts` 与 CLI 内的路径规则必须一致（两份实现同步改）。

### 调试端口与标语

- `pnpm dev` 不再默认加 `--remote-debugging-port`；`SQRAFT_DEBUG_PORT=<port>` 显式开启，`=0` 关闭。
- 欢迎页副标题改为「为 AI 原生而设计的 UI/UX 工具」。

### ai-tools 同步

- `update_node` 支持页面背景图（base64 内联，与 `image` 同构）。
- 新增 `export_png`（页面或节点集合、倍率、透明）、`import_font`（文件名 + base64，返回 family/weight/style）、`inspect_layout`（页面 + 可选节点集合）。
- 无页面时自动建页。
- 颜色入参接受 Token 或字面量。

### 格式版本

- `CURRENT_FORMAT_VERSION` 升到 5：新增 `page.backgroundImage` 与文档字体表；3/4→5 只补默认值，老文件渲染与行为不变。

## Testing Decisions

- 好的测试：只断言外部行为（给定文档状态与一次命令/一次调用，断言文档状态、撤销行为、返回载荷），不 spy 私有函数、不断言中间变量。
- **缝 1 · core 模型与命令**（最高缝）：空文档结构、背景图字段与迁移 v5、字体表、页面背景色写入路径、无页面时的建页命令。范本：现有 `core.test.ts` 的命令/撤销/迁移测试。
- **缝 2 · ai-tools 工具层**：字面量与 Token 两种入参、`export_png` 的倍率与透明参数、`import_font` 的字节与元数据、`inspect_layout` 的返回形状、无页面时自动建页、一次调用一条撤销。范本：现有 `ai-tools.test.ts`。
- **缝 3 · 渲染出口**：按倍率重绘的尺寸与内容（选区透明 / 页面带背景）、字体注册后的字重回退。纯函数优先，必要时用离屏 canvas 桩。
- **缝 4 · 主进程**：数据目录解析（平台 × home 组合）、迁移标记与复制逻辑、心跳超时踢连接。范本：`mcp-setup.test.ts` 的主进程侧测试形态。
- UI 接线（引导卡、徽标浮层、检查器背景组、字体下拉、开发者工具菜单）不进自动化，走手点清单。

## Out of Scope

- 字体子集化与字体授权校验。
- 背景图的 `stretch` 与手动偏移/缩放。
- 复制到剪贴板的 SVG/PDF 形式（只做 PNG）。
- 视图菜单的勾选状态、参考线吸附（仍留在票 14/13）。
- `CanvasView` 拆分（评审遗留的 P1-5，单独一轮）。
- 多人协作、跨文件组件库、导出 DTCG/CSS（M3）。
- Windows / Linux 上的手点验证。
- 旧目录自动删除。

## Further Notes

- **风险**：`FontFace` 注册是异步的，首帧可能回退到系统字体，导出前必须等 `document.fonts.ready`；心跳要两端一起改，旧 CLI 必须能被识别并降级；数据目录迁移后 CLI 更新滞后会"连不上"，需要容忍旧路径存在。
- **文档同步**：新增 ADR-0024（无默认设计系统、字面量纪律、字体嵌入）；AGENTS 更新"数据目录""调试端口""Token 纪律"三处；`docs/roadmap.md` 把导出与字体挂到 M3 之前。
- **票**：本规格按五个批次拆票，批次之间无交叉依赖，⑤ 依赖 ①（空文档）与 ②（连接列表）的最终形状。
