# 钢笔工具（Pen Tool）规格

## Problem Statement

Sqraft 目前只能画矩形、椭圆和直线：直线是两点之间的对角线段，无法表达曲线、折线和自定义轮廓。设计师想画一个圆角气泡、一条手绘风曲线、一个图标轮廓时，只能靠矩形和椭圆拼，或者放弃。AI 侧同样只能生成矩形/椭圆/直线，无法产出任何非规则形状。

路线图的 M2 已经把「钢笔路径（锚点/手柄编辑）」列为设计能力主体的一部分，但文档模型里 `path` 类型从建立至今没有任何代码创建它，渲染器甚至会把它画成一个矩形框。

## Solution

新增一支完整的贝塞尔钢笔：

- 工具条「直线」右侧新增钢笔入口，默认快捷键 `P`。
- 点击落角点，按下拖拽落平滑锚点（镜像手柄），`⌥` 断链，双击锚点归零手柄。
- 点回首锚闭合；`Enter` / 双击空白结束开放路径；`Esc` 结束并保留。
- 绘制期可 `⌘Z` / `Delete` 回退最后一个锚点，草稿不进文档。
- 画完可双击进入锚点编辑，拖锚点、拖手柄改形状；拖本体移动整条。
- 路径成为普通文档节点：可移动、缩放、删除、撤销、保存，并可通过检查器改填充、描边、闭合状态。
- AI 工具同步支持创建、修改和读取路径，仍只接受 Token 引用。

## User Stories

1. 作为设计师，我希望工具条里有钢笔工具，这样我能画矩形、椭圆、直线之外的任意形状。
2. 作为设计师，我希望按 `P` 就能切到钢笔，这样我不用离开键盘。
3. 作为设计师，我希望单击落下角点，这样我能画折线轮廓。
4. 作为设计师，我希望按下并拖拽落下一个平滑锚点，这样我能一笔画出曲线。
5. 作为设计师，我希望拖拽时对侧手柄方向相反但长度保留，这样曲线顺滑且不会改变另一侧的力度。
6. 作为设计师，我希望拖手柄时按 `⌥` 能断开联动，这样我能画出尖角（cusp）。
7. 作为设计师，我希望双击锚点把两侧手柄归零，这样我能把平滑点快速改成尖角。
8. 作为设计师，我希望看到从最后一个锚点到光标的橡皮筋预览，这样我知道下一段会落在哪里。
9. 作为设计师，我希望悬停首个锚点时看到闭合段预览，这样我知道点击会闭合。
10. 作为设计师，我希望点击首个锚点闭合路径，这样我能完成一个封闭形状。
11. 作为设计师，我希望闭合至少需要 3 个锚点，这样我不会造出退化的闭合形状。
12. 作为设计师，我希望 `Enter` 或双击空白结束开放路径，这样我能刻意保留一条开放线条。
13. 作为设计师，我希望 `Esc` 结束并保留路径，这样我下意识按 `Esc` 时不会丢掉已画的内容。
14. 作为设计师，我希望绘制中 `⌘Z` 删除最后一个锚点，这样我能就地纠错而不用退出工具。
15. 作为设计师，我希望绘制中 `Delete` / `Backspace` 也删除最后一个锚点，这样纯键盘也能纠错。
16. 作为设计师，我希望按住 `⇧` 把下一段约束到 45° 增量，这样我能精确画直线段和对角线。
17. 作为设计师，我希望靠近首个锚点 8px 内自动吸附闭合，这样闭合不需要像素级点击。
18. 作为设计师，我希望相邻重合的锚点自动去重，这样误双击不会产生零长度线段。
19. 作为设计师，我希望只能在页面内起笔，这样路径始终有明确的页面归属。
20. 作为设计师，我希望落笔之后的锚点可以越出页面边界，这样曲线能伸出画板。
21. 作为设计师，我希望切换工具或模式时保留正在画的路径，这样试别的工具不会丢工作。
22. 作为设计师，我希望点左栏、点工具条或窗口失焦时也保留路径，这样探索界面不会丢工作。
23. 作为设计师，我希望只落了一个锚点的草稿被丢弃，这样误点不会产生看不见的节点。
24. 作为设计师，我希望画完后自动回到选择工具，这样钢笔和其它绘图工具的肌肉记忆一致。
25. 作为设计师，我希望画完后新路径处于选中状态，这样我能立刻调整。
26. 作为设计师，我希望新路径命名为「路径 N」，这样图层列表里能认出来。
27. 作为设计师，我希望双击路径进入锚点编辑，这样画完还能精修曲线。
28. 作为设计师，我希望编辑时看到全部锚点，这样我能看清整条路径的骨架。
29. 作为设计师，我希望只有当前锚点显示两根手柄，这样画布不会被控制线淹没。
30. 作为设计师，我希望拖动锚点改变位置，这样我能重排轮廓。
31. 作为设计师，我希望拖动手柄改变相邻线段曲率，这样我能调出想要的弧度。
32. 作为设计师，我希望编辑时的手柄联动规则和绘制时一致（镜像、`⌥` 断链），这样不用记两套手势。
33. 作为设计师，我希望编辑态里拖路径本体移动整条，这样挪位置不用先退出编辑。
34. 作为设计师，我希望 `Esc` 退出锚点编辑但保留选中，这样我能接着做整体缩放。
35. 作为设计师，我希望再按一次 `Esc` 取消选中，这样逐级退出符合现有习惯。
36. 作为设计师，我希望一次锚点或手柄拖动只占一步撤销，这样撤销可预期。
37. 作为设计师，我希望检查器能把开放路径切换成闭合，这样画完改主意不用重画。
38. 作为设计师，我希望缩放路径时锚点和手柄一起等比缩放，这样形状比例不变。
39. 作为设计师，我希望路径能像其它节点一样移动、删除、撤销，这样它完全融入现有工作流。
40. 作为设计师，我希望点击判定跟随实际描边，这样细曲线外围的空白不会抢走点击。
41. 作为设计师，我希望有填充的闭合路径内部也能点中，这样填充形状的点击符合直觉。
42. 作为设计师，我希望还能从图层面板选中路径，这样再细的线也有兜底入口。
43. 作为设计师，我希望开放路径默认是 `color/text` 2px 描边，这样画完立刻可见。
44. 作为设计师，我希望闭合路径默认是 `color/primary` 填充，这样和现有形状的默认一致。
45. 作为设计师，我希望所有节点都能设置描边 Token 和线宽，这样直线、形状、路径都有统一的外观控制。
46. 作为设计师，我希望路径的描边端点和拐角是圆的，这样曲线看起来顺滑。
47. 作为设计师，我希望路径在任意缩放和 DPR 下都清晰，这样画布不会糊。
48. 作为设计师，我希望非活动页上的路径和页面一起淡化，这样双模式的规则保持一致。
49. 作为 AI 代理，我希望 `create_node` 接受 `points` 和 `closed`，这样我能生成矢量形状。
50. 作为 AI 代理，我希望 `points` 用父容器坐标并自动推导包围盒，这样我不用自己换算本地坐标和宽高。
51. 作为 AI 代理，我希望 `update_node` 能改 `points` 和 `closed`，这样截图自检后我能修正形状。
52. 作为 AI 代理，我希望 `read_document` 返回锚点数据，这样我能看见自己画了什么。
53. 作为 AI 代理，我希望 `create_node` / `update_node` 支持 `strokeToken` 和 `strokeWidth`，这样开放路径可见且仍然只引用 Token。
54. 作为 AI 代理，我希望路径有合理的默认样式，这样不用额外往返一次就能得到可见结果。
55. 作为设计师，我希望保存的 `.sqraft` 文件保留路径几何，这样重新打开不会丢曲线。
56. 作为设计师，我希望撤销/重做能恢复路径的创建和每次改形，这样编辑是安全的。
57. 作为设计师，我希望绘制中的预览不进入文档，这样自动保存、图层树和截图永远不会看到半成品。
58. 作为设计师，我希望钢笔只在编辑模式可用，这样拖动模式仍然是纯浏览。

## Implementation Decisions

### 数据模型

- 复用已有的 `path` 节点类型；在 `DocNode` 上新增可选字段 `vector`：

```ts
interface VectorAnchor {
  x: number;
  y: number;       // 锚点，节点本地坐标
  inX: number;     // 入手柄相对锚点的偏移
  inY: number;
  outX: number;    // 出手柄相对锚点的偏移
  outY: number;    // 全 0 表示该侧无手柄（尖角）
}

interface VectorPath {
  closed: boolean;
  anchors: VectorAnchor[];
}
```

- 锚点使用节点本地坐标；手柄使用相对锚点的偏移，这样「全 0 = 无手柄」是天然状态，缩放时手柄跟着锚点一起按比例变化。
- `width` / `height` 由锚点与手柄端点的包围盒推导。提交时把包围盒左上角归一化到节点原点（`x = 0, y = 0`），节点自身的 `x` / `y` 承接包围盒在父容器中的位置。
- 包围盒必须包含手柄端点；手柄伸出锚点之外时节点框变大。
- 提交后的路径至少 2 个锚点；闭合路径至少 3 个锚点。
- 相邻完全重合的锚点在提交前去重。
- 节点旋转沿用现有 `rotation` 语义（绕自身中心）；路径渲染应用同一旋转。现有命中测试忽略旋转，这条限制继续存在，不在本规格内修复。
- 新路径默认命名「路径 N」，类型标签仍为 `path`，工具条与图层使用钢笔图标。

### 命令与撤销

- 不新增命令类型。创建走 `node.create`，改形、移动、缩放、闭合切换走 `node.update`。
- 绘制期草稿只存在于 Web 客户端的 UI 状态，不写入文档、不进图层树、不参与自动保存和截图。
- 结束时一次性 `node.create` 整条路径，撤销一步删掉整条。
- 一次锚点拖动或手柄拖动 = 一步 `node.update`。
- `patch.vector` 和 `style` 一样是整体替换，调用方先展开旧值。
- `node.update` 对路径的尺寸规则：
  - 提供 `vector` 时以 `vector` 为准，重新推导 `width` / `height`；同时提供的宽高被忽略。
  - 只提供 `width` / `height` 时，锚点与手柄按新旧尺寸比例缩放。
  - 只提供 `x` / `y` 时只移动节点，不动锚点。
  - 闭合切换通过整体替换 `vector` 实现；锚点少于 3 个时抛错且不占撤销位。
- 命令执行期不调用 `Date.now`、随机数或 IO；节点 id 在命令创建前生成。

### 渲染

- `RenderBackend` 新增路径绘制方法，签名接收节点、`VectorPath`、填充色、描边色、线宽。Canvas 2D 后端用 `moveTo` / `lineTo` / `bezierCurveTo` / `closePath` 实现。
- 线段两端手柄都为零时退化为直线；任一侧有手柄时用三次贝塞尔。
- 描边端点与拐角取 `round`；填充使用非零规则。
- 没有填充色的路径只描边；有填充色的开放路径按画布默认行为隐式闭合后填充。
- 路径遵守现有 `rotation`、非活动页透明度、隐藏/锁定规则。
- 绘制期的曲线、锚点、手柄和闭合高亮属于 UI 叠加层（和选中框、参考线同类），不经过文档渲染路径。

### 钢笔交互

- 工具条「直线」后新增钢笔按钮；注册动作 `tool.path`，默认键位 `P`，可在快捷键面板修改，tooltip 从注册表读取。
- 点击 = 角点；按下拖拽 = 平滑锚点。拖拽时默认镜像：对侧方向相反、长度保留；按住 `⌥` 只动当前侧（断链）。
- 双击锚点把 `in` / `out` 两侧手柄归零。
- 点回首锚闭合；`Enter` 或双击空白结束开放路径；`Esc` 结束并保留。
- 绘制中 `⌘Z`、`Delete`、`Backspace` 删除最后一个锚点，且不触发文档撤销。
- `⇧` 把下一段约束到 45° 增量。
- 靠近首个锚点 8px 内吸附并高亮闭合。
- 必须在页面内起笔；后续锚点可越界，路径不裁剪。
- 切工具、切模式、点左栏/工具条、窗口失焦都按 `Esc` 规则收尾：锚点数 ≥ 2 提交，1 个丢弃。
- 结束后回到选择工具并选中新路径。
- 拖动模式不响应钢笔；点工具按钮会自动切回编辑模式（沿用现有绘图工具行为）。

### 锚点编辑

- 双击路径进入锚点编辑态；该状态是 UI 状态，不进文档。
- 编辑态隐藏 8 个缩放手柄，显示全部锚点；只有当前锚点显示两根手柄。
- 拖锚点或手柄改形状；拖本体移动整条路径，不退出编辑态。
- 手柄联动与绘制时一致：默认镜像、`⌥` 断链。
- `Esc` 退出编辑态并保留选中；再按 `Esc` 取消选中。点画布空白同样退出并取消选中。
- 切换选中、切模式、切页、重新载入时清空编辑态。
- 本轮只支持单个当前锚点；不做框选、多选、增删锚点。

### 命中测试

- 无填充路径与开放路径按实际几何判定：把每段贝塞尔采样成折线，计算点到线段距离，容差 `5 / zoom` 世界单位。
- 有填充的闭合路径同时支持内部命中（采样多边形 + 点在多边形内）。
- 图层面板始终可选，作为细线的兜底入口。
- 命中顺序与现有规则一致：页面 → 子节点从后往前。

### 检查器

- 新增通用「描边 Token + 线宽」，对所有非页面节点生效；直线、矩形、椭圆顺带获得描边控制。
- 路径额外显示「闭合」开关，走 `node.update` 整体替换 `vector`。
- 默认样式：开放路径 `stroke: color/text`、`strokeWidth: 2`、无填充；闭合路径 `fill: color/primary`、无描边。
- 未闭合路径若显式设置了填充，按隐式闭合区域填充。
- 路径不显示圆角、字号等无关字段。

### AI / MCP

- `create_node` 增加 `points`、`closed`、`strokeToken`、`strokeWidth`，`kind` 枚举加入 `path`。
- `points` 使用**父容器坐标**（与 `x` / `y` 同一坐标系），服务端归一化为节点本地坐标并推导 `x` / `y` / `width` / `height`。路径的 `x` / `y` / `width` / `height` 可省略，提供也以点集推导为准。
- `create_node` 的 `required` 从 `kind + width + height` 放宽为仅 `kind`；非路径节点缺省宽高仍按 100 处理，行为与现状一致。
- `update_node` 增加 `points`、`closed`、`strokeToken`、`strokeWidth`；`points` 同样是父容器坐标，更新后重新推导节点框。
- 路径至少 2 个锚点；`closed: true` 至少 3 个锚点，否则报错。
- 颜色仍只接受 Token：`fillToken` / `strokeToken` 都走现有 `assertToken`，禁止字面量。
- 默认样式与 GUI 一致：闭合默认 `color/primary` 填充；开放默认 `color/text` 2px 描边；显式 Token 覆盖默认值。
- `read_document` 的节点序列化加入 `vector`（`closed` 与全部锚点/手柄），否则模型看不到自己画出的形状。
- 工具描述更新，说明 `points` 的坐标系、手柄偏移、闭合约束和默认样式。

### 文档

- 新增 ADR-0012，记录矢量路径模型（本地坐标、手柄偏移、包围盒推导、整体替换与缩放规则）。
- 同步架构文档：文档模型章节补 `vector`，渲染章节补路径后端方法，画笔行为章节补钢笔与锚点编辑。
- 术语表新增「钢笔路径」「锚点」「入/出手柄」「草稿」等词条，并明确「路径」不是「直线」的同义词。
- 路线图 M2 的「钢笔路径」标记为已交付；布尔运算仍留在范围外。

## Testing Decisions

好的测试只验证外部可观察行为：给定命令和几何输入，断言文档状态、推导出的宽高、撤销结果和命中结果；不测试 Canvas 内部调用、不做 DOM 快照、不依赖渲染像素。

### 测试 seam

只使用一个既有 seam：`@sqraft/core` 的 vitest。

- 最高层是 `DocStore.apply(...)` + core 导出的纯几何函数；这是现有测试已经在用的层。
- 不新增测试运行器：渲染包、AI 工具包和 Web 客户端目前都没有测试运行器，本规格不引入新基础设施。
- 路径几何（包围盒归一化、缩放、采样、点在多边形内）放在 core 的纯函数里，保证能在 Node 下测试，符合「core 不依赖 DOM」的不变量。

### 测试内容

- 路径创建：`node.create` 带 `vector` 后节点可读、锚点完整；撤销后节点消失。
- 包围盒归一化：锚点与手柄的极值决定宽高；手柄伸出锚点时框变大；归一化后最小坐标为 0。
- 缩放：只改 `width` / `height` 时锚点与手柄按比例缩放；同时给 `vector` 时以 `vector` 为准。
- 闭合约束：少于 3 个锚点切换到闭合会抛错，且不产生撤销记录。
- 整体替换与撤销：一次 `node.update` 改形后撤销恢复到上一版几何。
- 几何采样：贝塞尔采样点落在预期区间；有填充的闭合路径内部点命中、外部点不命中。
- 回归：现有 13 个 core 测试全部保持通过。

### 手工验证

Web 客户端沿用现有的 Playwright 手工验证方式，不写进 CI。至少覆盖：

- `P` 切钢笔 → 页面内点击/拖拽画曲线 → 闭合 / `Enter` / `Esc` 三种收尾。
- 绘制中 `⌘Z`、`Delete` 回退锚点，文档撤销栈不受影响。
- `⇧` 45°、首锚吸附、重合点去重。
- 双击进入锚点编辑 → 拖锚点/手柄/本体 → `Esc` 层级。
- 检查器改描边、改填充、切闭合。
- 命中：细曲线空白区不抢点击，填充闭合路径内部可点。
- AI：`create_node` / `update_node` 带 `points` 后画布可见，`read_document` 能读回锚点。

## Out of Scope

- 在已有路径上插入/删除锚点、断开路径、连接两条路径。
- 锚点框选、多选、批量移动。
- 布尔运算（合并/减去/交集/排除）、路径查找器。
- SVG 导入/导出、SVG `d` 字符串作为内部存储。
- 渐变、虚线、可变线宽、描边对齐方式、文本沿路径。
- 路径之间的吸附、页面参考线吸附（`⇧` 45° 与首锚吸附保留）。
- 旋转后的精确命中（沿用现有「忽略旋转」的限制）。
- 在画板/分组内部用 GUI 起笔画路径（现有绘图工具都只落在页面层级；AI 仍可指定父节点）。
- 富文本与路径的组合、组件化路径、变体属性。
- 协作、云端存储、增量操作日志。

## Further Notes

- `Esc` 在钢笔草稿期间是「结束并保留」，与其它工具的「取消」不同；这是为了不丢失一笔画到一半的曲线。取消整条路径依靠 `⌘Z`（提交后）或绘制中删光锚点（草稿丢弃）。
- 绘制期预览放在 UI 叠加层，是 `CanvasView` 里选中框/参考线同一类局部例外，不违反「渲染只经 RenderBackend」。
- 草稿拦截 `⌘Z` / `Delete` / `Backspace` 时优先于全局快捷键分发；焦点在输入框内不拦截。
- 采样容差只在命中测试使用；渲染仍用真实贝塞尔，避免高倍缩放时出现折线。
- `.sqraft` 快照天然包含 `vector`，旧文件没有该字段也能正常打开，无需迁移。
- AI 工具 schema 的变更基本是增量，唯一的行为变化是 `width` / `height` 不再强制；非路径节点的运行时默认值保持 100。
