# 悬停子元素边界（Child Outlines）

日期：2026-10-29
状态：已实现

## 目标

指针停在画板里时，直接看到该画板**一级子元素**的边界，便于判断“每个子元素到哪儿为止”。纯只读信息层：不进文档、不进撤销、不影响命中与选中。

## 行为

- 触发：编辑模式 + 选择工具 + 没有进行中的画布手势。
- 容器：指针下**最深**的 `frame` / `component` / `instance`。
  - 页面不算容器（否则页面空白处会描出所有画板）。
  - 分组不算容器（边界由子节点并集决定）。
  - 实例算容器：未进入实例上下文时也能看到实例内部一级子元素的边界。
- 内容：容器的直接子元素（一级），只画**可见**的；锁定的照画。
- 裁剪：容器开启「裁剪内容」时，描边裁到容器边界。
- 时机：进入容器的第一帧就出现；同一容器内移动不重绘（`hoverContainerId` 不变即视为无变化）。
- 隐藏：拖动 / 缩放 / 绘制 / 钢笔手势进行中整层消失；非活动页悬停不画；行内文本编辑与锚点编辑时不画。

## 视觉

- 1 屏幕像素中性灰虚线：`rgba(15, 23, 42, 0.5)`，dash `[4,4]`，无名称标签。
- 先铺一层 `rgba(255,255,255,0.55)` 2px 发丝线做衬底，保证深色填充上也看得清。
- 画在选中框**下面**；选中框、悬停文本虚线、参考线、落点高亮仍然压在上面。
- 容器自身不加框——只描子元素，避免和落点高亮混淆。

## 实现

- `apps/web/src/canvas/child-outlines.ts`：`hoverContainerAt`（容器判定）、`paintChildOutlines`（裁剪 + 两遍描边）。
- `apps/web/src/components/CanvasView.vue`：`updateHover` 里更新 `hoverContainerId`，`draw()` 在选中框之前调用。
