# 布局自适应与右键菜单

## Problem

1. 画布只会在第一次拿到尺寸时适配一次视图：窗口拖小以后缩放不变、内容还是那么大，用户得手动按 `⇧1` 才能看全；顶部工具栏、左栏、检查器也不会随窗口收放，窄窗口下浮层互相压住。
2. 取素材只能先精确选中再按 `⌘⇧C`：想复制某个页面或某个元素，右键菜单里没有“就地复制”的入口。

## Solution

按两批交付，每批独立可验：

1. **右键菜单**：画布上右键页面本体/元素、左栏右键页面行/图层行 → 自绘上下文菜单；页面/元素都提供「复制为 PNG」（页面 2× 带背景、元素透明底），导出落盘仍走 `⌘⇧E` / 文件菜单。
2. **窗口自适应**：画布在窗口尺寸变化后自动重新适配（只在不打断手动视角的前提下）；工具栏放不下的分组收进「⋯」；左右面板可折叠，窄窗口自动收起。

## User Stories

1. 作为设计师，我希望在画布上右键一个页面就能复制整页 PNG，这样我不用先去左栏找那一页。
2. 作为设计师，我希望右键一个元素（或整组选中）只复制它们、透明底，这样我能直接把素材发给别人。
3. 作为设计师，我希望右键复制固定 2×、不弹倍率对话框；要 1×/3× 或落盘时再用 `⌘⇧E`。
4. 作为设计师，我希望右键页面/元素时它顺带被选中，这样菜单里的“复制 / 重命名 / 删除”作用对象和画面对得上。
5. 作为设计师，我希望窗口拖小后画布内容跟着缩小、始终看得到完整页面，这样我不用每次按 `⇧1`。
6. 作为设计师，我希望我手动放大到 300% 看细节时，拖窗口不会把视角抢回去。
7. 作为设计师，我希望窄窗口下工具栏收起次要按钮、左右面板自动收起，这样画布不会被人为压没。

## Implementation Decisions

### 右键菜单

- **入口**：画布 `.viewport` 与左栏页面行/图层行；空白处右键不弹菜单（先点一下对象）。
- **菜单**：自绘 Vue 浮层（玻璃风格、右上角快捷键提示、贴边翻转、Esc / 点外部关闭、↑↓ + Enter），两套内容：
  - 页面：适配该页 / 复制为 PNG / 重命名 / 删除页面（只剩一页时禁用）
  - 元素：复制 / 复制为 PNG / 重命名（多选时禁用）/ 删除
- **多选语义**：右键对象若已在选区里，保持整个选区（复制/删除作用于整组）；不在选区里则右键即单选。
- **复制为 PNG**：与 `⌘⇧C` 同一路径——页面固定 2×、带页面背景色/背景图；元素透明底、合并包围盒；直接进系统剪贴板，不弹保存框。成功/失败在底部给轻量提示；内容为空或超出导出像素上限时给出失败提示。
- **导出 PNG（落盘）**：只保留 `⌘⇧E` / 文件菜单入口，复用倍率对话框（1×/2×/3×），默认导出“当前选择或活动页”，文件名 `<文档名>.png`。
- **不改**：文件格式、`renderPng` 的渲染规则、MCP 的 `export_png`。

### 窗口自适应

- **画布**：`ResizeObserver` 更新视口尺寸后防抖 120ms；只有“视角还停在适配结果上”（`fitted`）才重新适配（编辑=活动页、拖动=全部页面）。手动缩放/平移/飞行定位/适配按钮会刷新这个状态：适配置 true，手动操作置 false。
- **工具栏**：`max-width` 扣掉左右面板占位，超出的分组按优先级收进「⋯」（文档胶囊 → 打开/保存 → 快捷键入口 → 撤销/重做）；面板状态变化时也重算。
- **面板**：左栏/检查器各有一个边缘把手切换，状态记 `localStorage`；窗口宽度低于 1040（左栏）/1180（检查器）自动收起，宽回来按用户偏好恢复；手动切换优先（清掉自动收起标记）。
- **工具栏居中**：按画布区（扣掉面板）居中，而不是按窗口居中。

## Testing Decisions

- 纯函数进单测：文件命名（`export-name.ts`）、旋转热区（已有）、`rotateZoneAt`。
- DOM 交互（右键菜单、溢出收纳、面板折叠、resize 适配）不进自动化，走手点清单：
  - 右键页面/元素/空白；多选里右键；复制为 PNG 粘出来检查尺寸、背景与透明底。
  - `⌘⇧E` / 文件菜单导出 1×/2×，检查文件名与尺寸。
  - 拖小窗口：内容跟着缩小；手动 ⌘+滚轮放大后再拖窗口，视角不被抢。
  - 窄窗口：工具被收进「⋯」且菜单里的项可用；左右把手切换 + 重启后状态保留。

## Out of Scope

- 导出 JPG/SVG/WebP、透明开关、批量导出多页。
- 记住每个文件的缩放与滚动位置。
- 面板拖拽调宽、面板停靠位置自定义。
