# 画布拖拽换父级（拖入画板 / 跨页面）

日期：2026-10-29
状态：已实现

## 目标

把画布上的元素拖进另一个画板、拖到页面根、跨页面搬动，父子关系随落点真实改变（不再只是“视觉上盖上去”）。换父级是结构变更，必须与几何修正一起作为**一个撤销条目**；落点判定与反馈全部在 UI 层，命令仍是 core 已有的 `node.reparent`。

## 落点判定

每帧按指针世界坐标求落点：

```
page = pageAt(指针)
没有 page            → 无落点（只在原父级里平移）
有 page、指针在容器里 → 最深的 frame / component（跳过实例、锁定、隐藏、
                       被拖节点自身及其子树）
有 page、指针在空白   → 页面根
```

- 跨页判定只看指针下的页面，**不看** `ui.activePageId`：拖动中可以悬停任意页面。
- 页面之间重叠时沿用 `pageAt` 的“先到先得”（`rootIds` 顺序）。
- 指针落在所有页面之外 = 不可换父级（保持“节点可以拖出页面边界”的现有能力）。
- 分组不是落点：分组边界由子节点并集决定，没有稳定的“内容区”。

## 合法性规则

| 被拖节点 | 允许的落点 |
| --- | --- |
| 普通节点 / 画板 / 实例根 | 任意 frame、component、页面根 |
| **主组件** | 只能页面根（core 强制页面顶层） |
| **组件的子节点** | 同一组件子树内（含组件自身），不能拖出 |
| **实例子树内的节点** | 无（只能平移、改覆盖字段、填插槽） |
| 页面 | 不可拖（页面只拖名称标签） |

- 不合法时**沉默拒绝**：不画高亮、不画插入线、不弹提示；松手按原父级平移（组件子节点原地不动）。
- 环（移进自己的后代）由遍历跳过 + `node.reparent` 兜底。
- 锁定容器不可作为落点（与 `containerAt` 一致）。
- 新建节点的落点判定仍走 `containerAt`：**新建可以落进组件，拖拽不行**（组件结构只经“选区创建组件”和实例同步变更）。

## 落下语义

| 情况 | 命令 |
| --- | --- |
| 落点 = 原父级、父级无布局 | 仅 `node.update` 的 x/y |
| 落点 = 原父级、父级有布局 | `node.reparent`（同父 + 投影索引）= 重排 |
| 落点是别的 frame / component | `node.reparent`，`index` 省略 = 置顶；x/y = 世界坐标 − 目标原点 |
| 落点是布局容器 | `node.reparent` + 投影索引；离开布局父级时把 `fill` 归一成 `fixed` |
| 布局容器 + `⌘` | `node.reparent` 保留世界坐标 + `layoutAbsolute: true` |
| 落点是页面根 / 跨页 | `node.reparent` 到 `page`，世界坐标不变 |

- 多选：每个移动根（父节点也在选区里的子节点不重复参与）各自过规则表；能落的换父级、不能落的照旧平移。整批命令 = 一次撤销。
- 多根一起落进布局容器时按文档 z 序分配连续插入索引；落进非布局容器按 z 序依次追加（保持相对叠放）。
- 拖入实例插槽仍由 `slot.fill` 优先接管，不做普通换父级。

## 拖拽过程反馈

- 合法落点画虚线外框 + 淡填充 + 「移入画板 / 移入组件 / 移入页面」标签；落点不会改变父级时不画（例如指针仍在原父级里）。
- 布局落点画插入线（横跨内容区），同时**兄弟节点让出空位**、hug 容器跟着变尺寸（120ms ease-out）；**布局落点不做吸附**，位置最终由求解器决定。`⌘` 落成绝对定位时恢复吸附、不画插入线与让位预览。详见 `docs/specs/layout-insert-preview.md`。
- 预览仍是“元素跟着指针走”；松手那一帧由求解器归位。

## 参考线与吸附

- 参考线上下文跟随落点父级：落点是容器/页面就用它的兄弟 + 内容区 + 边界；指针在页面外时退回“所有根同父”的上下文，跨父则不出线。
- 单条缓存（按父级 id），只有落点变化才重算。
- `⌥` 仍然全程关闭吸附；布局落点默认不吸附。

## 跨页面

- 拖动中只画目标页的高亮，**不切活动页**。
- 松手后：先提交 reparent，再把 `ui.activePageId` / `ui.expandedPageId` 指向目标页。
- 不走 `setActivePage`：它会按“父级 = 页面”过滤选区，落进画板里的节点会被清掉。

## 边缘自动滚屏

- 指针进入画布视口边缘 40px 起滚，速度按 `(1 − d/40)²` 变速，上限约 960 屏幕像素/秒，随缩放换算成世界位移。
- 每帧平移视口后按**同一屏幕坐标**重算世界指针、落点、插入线、参考线；不需要重新按下指针。
- 指针离开画布（指针捕获期间）不滚。
- 只在移动拖拽中生效；绘制、缩放、重排手势不滚。

## 取消与撤销

- 拖动中 `Esc` 放弃整次手势：不产生命令，几何与父级都保持原样。`Esc` 优先级排在“退出实例上下文”之前。
- 跨页落下后撤销只回放文档：节点回原页，活动页**不回退**（视图是“我在看哪儿”，不是文档事实）。需要时手动切回。

## 实现

- `apps/web/src/canvas/drop-target.ts`：`dropTargetAt`（落点）、`dropAllowed`（规则表）、`instanceAncestorOf` / `componentOwnerOf`。
- `apps/web/src/canvas/drop-overlay.ts`：`paintDropTarget`（容器虚线框 / 整页外框 + 标签）。
- `apps/web/src/canvas/layout-preview.ts`：插入让位预览（求解 + 120ms 缓动），见 `docs/specs/layout-insert-preview.md`。
- `apps/web/src/components/CanvasView.vue`：`updateMoveDrag`（每帧重算）、`commitMoveDrag`（命令批次）、`autoScrollStep`、`cancelDrag`、让位动画 tick。
- `apps/web/src/canvas/layout-drag.ts`：`reorderIndexAt` / `reorderGuide` 复用，`containerAt` 保持新建语义不变。
- core：无新命令、无新校验，复用 `node.reparent` 与 `solveLayout`。
