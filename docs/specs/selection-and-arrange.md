# 选择与排列（Selection & Arrange）规格

## Problem Statement

Sqraft 现在能画（矩形/椭圆/多边形/直线/钢笔路径/文本/图片/画板）、能改属性（几何/样式/效果/自动布局/组件/实例/插槽/Token），但**「改稿」这一层几乎是空的**：

- 想再要一个一样的矩形，只能重新画一遍或去检查器抄数字；
- 想同时选中三张卡片，只能按住 `⇧` 一个个点，空白处一拖反而把选区清空；
- 想把两个图层换个上下顺序，只能删掉重建（图层面板也不能拖）；
- 想把几个元素整体挪动、等距排开、左对齐，只能逐个改 X/Y，靠目测找间距；
- 想把一组元素当整体反复用，没有分组；
- 想把一个元素转 15°，只能去检查器里填数字；
- 画布恒为白底，没有标尺、没有参考线，只能靠拖动时一闪而过的吸附线临时对齐；
- 网格点阵永远亮着，想关掉或关掉吸附没有办法。

后果是：**AI 生成一张稿子之后，人工修一遍的成本比重新画还高**。工具变成了"只能生成、不能修改"，路线图里"AI 生成 → 人工兜底 → 截图自检"的闭环缺了人工那一段。

## Solution

把「改稿闭环」补齐，目标不是复刻 Figma 全量，而是**能独立画完一张页面并改稿**：

- **剪贴板**：`⌘C` / `⌘X` / `⌘V` / `⌘D` / `⌘A`，写系统剪贴板的自定义 MIME，同文档、跨文档都能粘；带图节点把图片内联，引用（Token / 组件母版）能带就带、带不了就按规则降级。
- **选择**：空白处拖出框选（相交即选），`⇧` 追加；多选后检查器显示选区包围盒，改 X/Y 平移整体、改 W/H 等比缩放整体；画布上多选也有 8 个手柄，等比缩放（几何 / 圆角 / 字号 / 描边宽 / 效果半径 / 图片裁切同步）。
- **排列**：对齐（左 / 水平居中 / 右 / 上 / 垂直居中 / 下）与分布（水平 / 垂直等间距）；四角外侧出现旋转热区，`⇧` 吸附 15°，多选绕选区包围盒中心旋转。
- **组织**：层级 `⌘]` / `⌘[` / `⌥⌘]` / `⌥⌘[`，图层面板支持拖拽重排与拖入其他容器；`⌘G` 分组、`⌘⇧G` 解组（Figma 式组）。
- **视图与辅助**：顶部/左侧标尺，可拖出文档级参考线并参与吸附；页面背景色（复用页面节点的填充）；网格显隐与吸附开关。
- **agent 侧同步**：`group_nodes` / `arrange_nodes` / `duplicate_node` 三个工具，一次调用仍是一条撤销。

## User Stories

### 复制与粘贴

1. 作为设计师，我希望 `⌘C` 复制当前选区，这样我不用重画就能得到一份同样的图层。
2. 作为设计师，我希望 `⌘X` 剪切选区，这样我能把它挪到别的容器里而不用拖。
3. 作为设计师，我希望 `⌘V` 粘到鼠标所在位置，这样粘出来的东西就在我眼睛看的地方。
4. 作为设计师，我希望鼠标不在画布上时 `⌘V` 落在原位置偏移 10px，这样连续粘贴不会完全重叠成一坨。
5. 作为设计师，我希望 `⌘D` 原地复制并偏移 10px，这样我能一键做出第二个卡片。
6. 作为设计师，我希望 `⌘A` 全选当前页的顶层图层，这样我能一次性对齐整页。
7. 作为设计师，我希望复制带图片的图层时图片跟着走，这样粘到另一个文件里不会变成占位块。
8. 作为设计师，我希望把图层复制到另一个文档里仍然可用，这样我能把组件从旧稿搬进新稿。
9. 作为设计师，我希望粘进新文档时缺失的 Token 定义自动带过去，这样颜色不会静默变成字面色值。
10. 作为设计师，我希望目标文档已有同名 Token 时沿用它的值，这样我不会意外覆盖设计系统。
11. 作为设计师，我希望粘一个母版不在目标文档里的实例时它自动脱离为画板，这样我至少能看到外观而不是报错。
12. 作为设计师，我希望复制主组件会得到一个新的主组件副本，这样我能基于它做变体而不是共用同一个母版。
13. 作为设计师，我希望复制实例仍然指向同一个母版，这样改母版时两份实例一起更新。
14. 作为设计师，我希望在输入框里 `⌘C` / `⌘X` 仍然是复制文本，这样编辑器不会抢走系统习惯。
15. 作为设计师，我希望粘贴时输入框优先（画布焦点才粘节点），这样我不会在改字号时粘出一堆图层。
16. 作为设计师，我希望一次粘贴是一条撤销，这样 `⌘Z` 能把整批图层收回去。

### 选择

17. 作为设计师，我希望在空白处拖出选框选中相交的图层，这样我不用一个个点。
18. 作为设计师，我希望框选不穿透容器，这样我框住一张卡片时不会连带选中里面的文字。
19. 作为设计师，我希望框选跳过锁定与隐藏的图层，这样我不会选中不该动的东西。
20. 作为设计师，我希望 `⇧` + 框选是追加而不是替换，这样我能分两次框出想要的集合。
21. 作为设计师，我希望在实例上下文里框选只选当前层级的兄弟，这样我不会把母版结构搅乱。
22. 作为设计师，我希望点击空白仍然清空选区，这样取消选择不需要按 `Esc`。
23. 作为设计师，我希望方向键微移选区 1px、`⇧` + 方向键 10px，这样我能像素级对齐。
24. 作为设计师，我希望 `F2` 在画布上直接改图层名，这样我不用去图层面板找。

### 排列与对齐

25. 作为设计师，我希望多选时检查器显示选区包围盒，这样我知道这组东西整体多大、在哪。
26. 作为设计师，我希望多选改 X/Y 是整体平移，这样我能精确摆放一组元素。
27. 作为设计师，我希望多选改 W/H 是整体等比缩放，这样我不会把卡片拉变形。
28. 作为设计师，我希望多选拖手柄时圆角、字号、描边宽、效果半径一起按比例变，这样缩小的卡片看起来还是同一个设计。
29. 作为设计师，我希望多选缩放时图片的裁切区域同步缩放，这样图不会被"重新构图"。
30. 作为设计师，我希望单选节点时对齐到父容器内容区，这样我不用先量父容器。
31. 作为设计师，我希望多选时对齐到选区包围盒，这样这组东西能整体贴到左边。
32. 作为设计师，我希望三个以上节点能水平/垂直等间距分布，这样列表不会一边挤一边空。
33. 作为设计师，我希望父容器有自动布局时对齐按钮置灰，这样我不会造出和布局打架的坐标。
34. 作为设计师，我希望四角外侧出现旋转热区，这样我能直接在画布上转。
35. 作为设计师，我希望旋转时按 `⇧` 吸附到 15° 的整数倍，这样我能转出正 45°。
36. 作为设计师，我希望多选旋转绕选区包围盒中心，这样一组元素是整体转而不是各自自转。
37. 作为设计师，我希望旋转手柄与缩放手柄不打架（角外侧是旋转、手柄上是缩放），这样我不会误操作。

### 层级与分组

38. 作为设计师，我希望 `⌘]` / `⌘[` 上下移动一层，这样调遮挡关系不用重画。
39. 作为设计师，我希望 `⌥⌘]` / `⌥⌘[` 直接置顶/置底，这样我能一次把元素提到最前。
40. 作为设计师，我希望在图层面板里拖拽重排，这样我能一次跨好几层。
41. 作为设计师，我希望把图层拖进另一个容器，这样换父级和调顺序是一个动作。
42. 作为设计师，我希望拖拽有插入位置指示线，这样我知道会落在哪一层。
43. 作为设计师，我希望 `⌘G` 把选区打成一个分组，这样我能把它当整体移动。
44. 作为设计师，我希望分组不裁剪、不填充，尺寸自动等于子节点并集，这样它不会凭空多出一块背景。
45. 作为设计师，我希望缩放分组等于缩放里面的子节点，这样整组放大时内容跟着放大。
46. 作为设计师，我希望 `⌘⇧G` 解组后子节点保持原来的位置和大小，这样解组不会让画面跳一下。
47. 作为设计师，我希望分组/解组各是一条撤销，这样我能快速试错。

### 视图与辅助

48. 作为设计师，我希望画布边缘有标尺，这样我能读出当前元素的位置与尺寸。
49. 作为设计师，我希望从标尺拖出参考线，这样我能给多个元素找一条共同的基准。
50. 作为设计师，我希望参考线随文件保存、按页面各自独立，这样换机器打开还是那几条线。
51. 作为设计师，我希望双击参考线能删掉、拖回标尺也能删掉，这样清理不留垃圾。
52. 作为设计师，我希望拖动元素时能吸附到参考线，这样对齐不用算像素。
53. 作为设计师，我希望 `⌘;` 一键隐藏/显示参考线，这样截图前画面是干净的。
54. 作为设计师，我希望页面背景可以设成 Token 或任意颜色，这样我能做深色页面或品牌底色。
55. 作为设计师，我希望 `⌘'` 关掉网格点阵、`⌥⌘'` 关掉吸附，这样精细调整时没有干扰。
56. 作为设计师，我希望这两个开关跨文件、跨启动保留，这样我不用每次重新设。

### agent

57. 作为 agent，我希望有 `group_nodes` 工具，这样我生成一组卡片后能把它们打成一个分组。
58. 作为 agent，我希望有 `arrange_nodes` 工具（对齐 / 分布 / 层级），这样我不用手算每个节点的 x/y 就能排整齐。
59. 作为 agent，我希望有 `duplicate_node` 工具，这样我能基于一个模板快速铺列表。
60. 作为 agent，我希望这三个工具和 UI 走同一套命令，这样我改的结果和用户改的完全一致、撤销行为一致。
61. 作为 agent，我希望一次工具调用只占一条撤销，这样用户能一键撤回我的整个动作。

## Implementation Decisions

### 数据模型

- **页面背景**：不新增字段，复用页面节点的 `style.fill`（`Paint`：Token 引用或字面色值）。缺省无填充 → 渲染按白色画板处理；投影不变。检查器选中页面时在「外观」组显示「背景」。
- **参考线**：`DocNode` 新增可选字段 `guides?: { x: number[]; y: number[] }`，只对 `type: "page"` 有意义。坐标是**页面本地坐标**（页面左上角为原点，不含页面在画布上的位置）。同一条线上重复拖出时去重（1px 内视为同一条）。
- **格式版本**：`CURRENT_FORMAT_VERSION` 升到 4，迁移 3→4 是纯补默认值（`guides` 缺省 `undefined`、页面 `style.fill` 缺省无），不改变已有文档的渲染结果。新建文档直接写 4。
- **分组**：复用已有的 `group` 节点类型，不新增字段。`group` 不承载自动布局（`layout` 只允许在画板/组件上），不裁剪（`clip` 恒 false），不参与填充/描边（`style` 保持空）。
- **参考线不进渲染器**：画在 UI 叠加层，和选中框、吸附线同一层，因此天然不出现在 MCP `screenshot` 里。

### 命令（新增，全部走 `DocStore.apply`，一次命令一条逆命令）

| 命令 | 语义要点 |
|---|---|
| `node.duplicate` | 入参是根节点 id 列表 + 偏移；整棵子树深拷贝、全部 id 重映射、`parentId`/`children`/`mainId`/`componentId`/`propertyDefs.targetMainId`/`propValues`/`overrides` 里的引用一并重映射；粘贴跨文档时由调用方先改写引用再下发 |
| `node.group` | 入参是选区 id + 新组 id；组插到选区里**视觉最上层**那个节点原来的位置；组 `x/y` 取子节点世界包围盒左上角，子节点坐标转成组内本地坐标 |
| `node.ungroup` | 子节点提升到组的父级、保持世界坐标、插入到组原来的 index 位置，组删除 |
| `node.align` | 入参是选区 id + 对齐方式（6 种）；单选对齐父内容区（有 padding 用内容区，否则用父边界），多选对齐选区包围盒；父为自动布局容器时命令拒绝执行（UI 也置灰） |
| `node.distribute` | 入参是选区 id + 轴向；少于 3 个节点拒绝；等间距分布，两端节点不动 |
| `node.reorder` | 入参是选区 id + 动作（上移一层 / 下移一层 / 置顶 / 置底）；**只改同一父级内的顺序**，多选时保持相对顺序；越界时是幂等的空操作（不产生撤销记录） |
| `node.scale` | 入参是选区 id + 缩放锚点与比例；几何按比例，`cornerRadius` / `fontSize` / `strokeWidth` / 效果半径与偏移 / `image.crop` 同比例；自动布局的 `hug`/`fill` 子项只缩位置不写死宽高；宽高下限沿用现有 8px（页面 200px） |

- 分组不新建 `group` 专用命令以外的命令：`node.group` / `node.ungroup` 内部展开成基础命令，与现有 `component.create` 的处理方式一致。
- 复制/粘贴不新增"粘贴"命令：剪贴板解码后由调用方下一条 `node.create`（或 `node.duplicate`），一条调用包在一次 `transact` 里。

### 剪贴板

- MIME：`application/x-sqraft+nodes`。`⌘V` 的优先级是 **sqraft 节点 > 图片 > 文本**（现状的图片/文本粘贴保持不变）。
- 载荷（JSON，版本化，为将来加字段留位）：

```jsonc
{
  "kind": "sqraft/nodes",
  "version": 1,
  "rootIds": ["..."],              // 复制时的根节点顺序
  "nodes": [ /* DocNode 扁平表，含子树 */ ],
  "tokens": { "brand/primary": { "type": "color", "value": "#5B5FE8" } },
  "assets": { "<assetId>": { "mime": "image/png", "base64": "..." } }
}
```

- 只带**被复制子树实际引用到的** Token 与图片，不整份复制设计系统。
- 落点：指针在画布上 → 粘到指针位置，父级取指针下的容器（画板/组件/分组/页面；不可作为父级则回落到活动页根）；指针不在画布上 → 原位置 +10px。多根节点整体平移，相对位置不变。
- `⌘D`：原位 +10px，父级不变。
- 跨文档降级规则：
  - 图片：`assetId` 是内容哈希，直接注册进资源库；已存在则复用，不重复写。
  - Token：目标缺失则连同定义一起复制；同名但值不同则**保留目标已有值**，引用指向它。
  - 实例：`componentId` 在目标文档不存在时，按 `component.detach` 语义脱离为画板（外观不变，失去组件关联）。
  - 主组件：复制得到新的主组件（新 id），`propertyDefs` 一起复制并重映射 `targetMainId`；同一次粘贴里若有指向它的实例，实例改指新母版。
- 体积：单张图片沿用 20MB 上限；超过时该图降级为占位（节点保留，`assetId` 指向不存在的资源），不整次粘贴失败。

### 快捷键（新增动作，全部进快捷键面板，可改键）

| 动作 | 默认键 |
|---|---|
| 复制 / 剪切 / 粘贴 / 原地复制 / 全选 | `⌘C` / `⌘X` / `⌘V` / `⌘D` / `⌘A` |
| 微移（1px）/ 微移（10px） | `←→↑↓` / `⇧←→↑↓` |
| 重命名图层 | `F2` |
| 分组 / 解组 | `⌘G` / `⌘⇧G` |
| 上移一层 / 下移一层 / 置顶 / 置底 | `⌘]` / `⌘[` / `⌥⌘]` / `⌥⌘[` |
| 显示网格 / 启用吸附 | `⌘'` / `⌥⌘'` |
| 显示参考线 | `⌘;` |

- 吸附不绑 `⇧⌘'`：注册表会把 `⇧` 吞成符号（`⌘"`），所以用 `⌥⌘'`。
- `⌘C` / `⌘X` / `⌘A` / `F2` / 方向键**不设为全局动作**：输入框内保持原生行为。`⌘V` 维持现状（全局），由粘贴逻辑自己判断焦点是否在输入框。
- 视图菜单新增「显示网格」「启用吸附」「显示参考线」三项，勾选状态与 `bindingRev` 同步（改键后菜单提示跟着变）。

### 手势

- **框选**：编辑模式下在空白处按下并拖动超过 3px 才进入框选（低于阈值仍是"点击清空"）；命中判定用节点包围盒与选框**相交**；只取当前页可见、未锁定、当前层级（实例上下文内为实例的直接子级）的节点；`⇧` 追加、否则替换；`Esc` 取消框选并恢复原选区。
- **多选手柄**：多选时 8 个手柄围绕选区包围盒；`⇧` 等比、`⌥` 从中心；拖动时实时下发 `node.scale`（一次拖拽一条撤销，用 `transact`）。
- **旋转**：四角手柄外侧 12px 热区（光标换成旋转样式）；角度取指针相对包围盒中心的极角，`⇧` 吸附 15°；单选绕自身中心（沿用现有 `rotation` 语义），多选绕包围盒中心同时改位置与角度；一次拖拽一条撤销。
- **参考线**：从标尺按下拖出（水平/垂直由起拖方向决定），拖动中显示数值；拖回标尺区域松手即删除；双击删除；`⌘;` 切换显隐（隐藏时也不参与吸附）。
- **吸附**：现有对齐吸附逻辑增加"参考线"这一组候选，优先级与兄弟/父边界同级；`⌥` 仍然临时关闭吸附；吸附总开关关掉时只保留 `⇧` 约束。
- **微移**：方向键 1px，`⇧` 10px；多选时整体平移；每次按键合并成一条撤销（连续按方向键在 300ms 内复用同一条事务）。

### 渲染与检查器

- 页面背景：渲染器在画页面底之前读 `page.style.fill`（Token 解析复用 `resolvePaint`），无填充时用白色；投影保持不变。
- 检查器：
  - 多选时「位置与尺寸」显示包围盒，X/Y 平移整体、W/H 等比缩放整体，旋转/不透明度维持"逐节点写同一值"。
  - 多选时新增一排对齐/分布图标；父为自动布局容器时置灰并给 tooltip 说明。
  - 选中页面时「外观」组出现「背景」字段。
- 图层面板：行支持拖拽（拖到行上=插入到该行位置，拖到容器行=放进容器），有插入指示线；面板显示顺序是倒序（`children` 反向），拖拽计算时统一换算回 `children` 索引。
- 标尺：顶部与左侧各 26px，浮在画布之上、不遮挡工具栏；刻度步进随缩放自适应（1/5/10/50/100/500px）；显示选区的位置与尺寸高亮。

### agent 工具（新增 3 个）

- `group_nodes({ nodeIds, name? })` → 返回新分组 id。
- `arrange_nodes({ nodeIds, action })`，`action` ∈ `align-left|align-h-center|align-right|align-top|align-v-center|align-bottom|distribute-h|distribute-v|bring-forward|send-backward|bring-to-front|send-to-back`。一次调用只做一件事，仍包在一次 `transact` 里。
- `duplicate_node({ nodeId, offsetX?, offsetY? })` → 返回新根节点 id 列表。
- 颜色仍然只接受 Token 引用；三个工具都不接受字面色值，也不改变"样式只接受 Token"的既有纪律。

## Testing Decisions

- **好测试的标准**：只测外部行为——给定文档状态与一次命令/一次调用，断言**文档状态**与**撤销行为**；不测内部实现（不 spy 私有函数、不断言中间变量）。手势类逻辑只测纯函数（给定指针序列 → 结果矩形/角度/比例），不测 DOM 事件绑定。
- **缝 1 · core 命令层**（最高缝，覆盖绝大部分逻辑）：`packages/core` 现有 `core.test.ts` 的命令/撤销/事务测试是范本。覆盖：复制子树 id 重映射与引用重映射、分组/解组的坐标与世界位置、对齐两种基准、分布等间距与 <3 拒绝、reorder 边界幂等、缩放比例（含字体/圆角/描边/效果/裁切与 hug/fill 子项）、页面背景与参考线字段、3→4 迁移。
- **缝 2 · 剪贴板编解码**（纯函数，不碰 Electron）：序列化 → 反序列化 round-trip、跨文档降级的四种情形（Token 缺失/冲突、母版缺失、图片复用）、体积上限降级、载荷版本号未知时拒绝。
- **缝 3 · 手势几何纯函数**：框选命中（相交/锁定/隐藏/实例上下文）、旋转角度吸附（15°）、多选包围盒缩放的映射（锚点/比例 → 每个节点的目标几何）。
- **缝 4 · ai-tools 工具层**：现有 `ai-tools.test.ts` 的范本（构造工具入参 → 断言文档状态与撤销条数）。覆盖三个新工具的入参校验、返回 id、一次调用一条撤销。
- UI 接线（手柄、标尺、面板拖拽、菜单勾选）不进自动化，走手点清单。

## Out of Scope

- 自动保存与崩溃恢复（下一轮）。
- 导出：PNG/@2x/SVG/PDF、DTCG、CSS 变量（M3）。
- 布尔运算、变体/枚举属性、富文本 runs、跨文件组件库、Section、Grid 自动布局、约束（pin）。
- 非等比的多选缩放、倾斜（skew）、自由变形。
- 复制粘贴到**其他应用**的可用形式（例如粘成 SVG/PNG）；本规格只保证 Sqraft 之间的节点互粘。
- 参考线吸附到节点、参考线的锁定/命名/分组、全局（跨页面）参考线。
- 画布小地图、缩略图导航。
- Windows / Linux 上的手点验证。
- 方向键微移的"按住加速"与自定义步长。
- 多窗口与协作（命令化模型已留门票，不在本轮）。
