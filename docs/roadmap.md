# Sqraft 路线图

> 前提：单人业余节奏。每个里程碑都是**可演示的完整切片**，不堆半成品。原型连线因 AI 全流程需求从 v2 提前进 v1（Q15 决策）。

## M1 — 编辑器内核（含 agent 冒烟测试）

- monorepo 工程、CI、测试框架
- 文档模型 + 命令系统（事务、撤销/重做、检查点）
- Canvas 2D 渲染：视口（平移/缩放/DPR）、矩形/椭圆/直线
- 图层面板、基础检查器（位置尺寸填充色）
- 可配置快捷键（统一注册表 + 录制面板，见 ADR-0011）已提前交付
- 文件：新建/打开/保存 `.sqraft`（快照 + 增量），File System Access 主路径 + 降级
- **Agent 冒烟测试**：命令层暴露最小工具集（读文档/建节点/改属性/截图），对话面板接一个模型跑通"生成一个卡片 → 截图 → 自检修正"闭环

## M2 — 设计能力主体

- 文本：单样式文本、DOM 浮层编辑、断行；字体导入嵌入
- 形状补全：**钢笔路径（锚点/手柄编辑）已交付**（ADR-0012）；**参数化多边形（含三角形）已交付**（ADR-0013）；星形（待补）
- **自动布局完整集**（本阶段最大攻坚）：方向/gap/padding/对齐/hug-fill-fixed/wrap/min-max/绝对定位子项；golden 测试集
- 组件/实例/组件属性统一模型（变体=枚举属性，布尔/文本/实例替换）

## M3 — 设计系统与交付

- Token：集合、引用解析、单一取值
- 设计系统面板（左栏第三 tab：按前缀分组、改值 / 新增走 `token.define`）已提前交付
- DTCG 导出 + CSS 变量生成
- 切图导出：PNG/@2x/SVG
- agent 工具纪律上线（样式只接受 Token 引用）

## M4 — AI 完整化

- 对话面板完整形态：多轮上下文（选中集、当前页）、BYOK 多供应商适配（DeepSeek/OpenAI/Claude/Ollama）
- MCP Server 正式发布（与对话面板共用工具 schema）
- 截图自检闭环打磨（定尺寸、区域截图）

## M5 — 多页面与原型

- 原型连线（页面间跳转）+ 演示模式；页面管理（新建/重命名/删除）已随无限画布提前交付
- agent 多页面生成：需求文档 → 多页面设计稿 + 连线

## v1.5 / v2 候选（按需排期）

富文本 runs、面板 dock 化、布尔运算、Section、按画板模式覆盖、组件库跨文件复用、WebGL2 渲染后端、多人协作架构激活（命令化模型已为其买好门票）。

## 里程碑风险表

| 阶段 | 风险 | 触发时的降级方案 |
|---|---|---|
| M2 | wrap 求解器收敛问题 | wrap 降为 M2.5，核心集先行发布 |
| M2 | 中文断行效果不达标 | v1 声明"中文换行基础支持"，禁则后置 |
| M1 | File System Access 在目标浏览器不稳 | 降级路径（下载/上传）即为默认体验 |
| M4 | 多模态截图在部分模型不可用 | 工具返回结构化摘要作为回退 |
