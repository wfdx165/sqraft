# Sqraft 路线图

> 前提：单人业余节奏。每个里程碑都是**可演示的完整切片**，不堆半成品。原型连线因 AI 全流程需求从 v2 提前进 v1（Q15 决策）。

## M1 — 编辑器内核（含 agent 冒烟测试）

- monorepo 工程、CI、测试框架
- Electron 桌面壳：MCP 宿主、文件 IPC、欢迎页与最近打开、文件关联
- 文档模型 + 命令系统（事务、撤销/重做、检查点）
- Canvas 2D 渲染：视口（平移/缩放/DPR）、矩形/椭圆/直线
- 图层面板、基础检查器（位置尺寸填充色）
- 可配置快捷键（统一注册表 + 录制面板，见 ADR-0011）已提前交付
- 文件：新建/打开/保存 `.sqraft`（快照 + 增量），系统对话框 + 原地写回（随桌面壳落地）
- **Agent 冒烟测试**：命令层暴露最小工具集（读文档/建节点/改属性/截图），由外部 agent 经 MCP 跑通"生成一个卡片 → 截图 → 自检修正"闭环（依赖桌面壳，见 M1 桌面版）

## M2 — 设计能力主体

- 文本：单样式完整面板（行高/字距/段距/对齐/大小写/装饰/列表/截断）、contenteditable 浮层、自动宽高；字体导入嵌入仍待补
- 形状补全：**钢笔路径（锚点/手柄编辑）已交付**（ADR-0012）；**参数化多边形（含三角形）已交付**（ADR-0013）；星形（待补）
- **改稿操作**（ADR-0023）已交付：复制/剪切/粘贴/原地复制/全选、框选、多选包围盒缩放、对齐与分布、旋转手柄、层级快捷键与面板拖拽、分组/解组、方向键微移、标尺与参考线、页面背景色、网格/吸附开关
- **自动布局完整集**已交付：方向/gap/四边 padding/对齐/hug-fill-fixed/wrap/min-max/绝对定位子项/拖拽重排；golden 测试集
- 组件/实例/插槽/文本、布尔、实例替换属性已交付（ADR-0014）；枚举属性与变体（组件集合）待补

## M3 — 设计系统与交付

- Token：集合、引用解析、单一取值
- 设计系统面板（左栏第三 tab：按前缀分组、改值 / 新增走 `token.define`）已提前交付
- DTCG 导出 + CSS 变量生成
- 切图导出：PNG/@2x/SVG
- agent 工具纪律上线（样式只接受 Token 引用）

## M4 — AI 完整化（MCP 单插槽）

- MCP Server 随桌面版发布：本机 HTTP 接入（Streamable HTTP，ADR-0026）、配置面板、多客户端串行
- 截图自检闭环打磨（定尺寸、区域截图）

## M5 — 多页面与原型

- **原型链接 + 演示模式已交付**（ADR-0032）：图层级点击跳转 / 返回上一屏、即时与淡入转场、页面级滚动、热区高亮；`set_interaction` 等 MCP 工具让 agent 能建可点击稿
- agent 多页面生成：需求文档 → 多页面设计稿 + 连线（链接工具已就绪，可跑通闭环）
- 动效（Smart Animate 式状态插值）单列为下一阶段：链接已是它的挂载点，转场类型里已预留

## v1.5 / v2 候选（按需排期）

富文本 runs、面板 dock 化、布尔运算、Section、按画板模式覆盖、组件库跨文件复用、WebGL2 渲染后端、多人协作架构激活（命令化模型已为其买好门票）。

## 里程碑风险表

| 阶段 | 风险 | 触发时的降级方案 |
|---|---|---|
| M2 | wrap 求解器收敛问题 | wrap 降为 M2.5，核心集先行发布 |
| M2 | 中文断行效果不达标 | v1 声明"中文换行基础支持"，禁则后置 |
| M1 | 各平台文件对话框/文件关联行为不一致 | 主进程统一封装；Win/Linux 先标注未验证 |
| M4 | 多模态截图在部分模型不可用 | 工具返回结构化摘要作为回退 |
